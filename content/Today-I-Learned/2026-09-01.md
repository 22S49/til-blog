### 어텐션 메커니즘 
- S2S 아키텍처 (컨텍스트 벡터) 의 병목 현상을 극복하기 위해서 나온 매커니즘
- 모든 상태를 활용 (모든 은닉 상태를 보관) ⇢ 품질이 좋아지지만 연산량이 많아져서 효율성 떨어질 수 있음
- 선택적 주의집중 ─ 처음에는 집중해야 할 곳을 알 수 없으므로 랜덤으로 초기화 후 학습을 통해서 어텐션 점수 부여
- **어텐션 헤드 (Attention Head)** ─ QKV 벡터
	- Query와 Key를 통해서 Attention Weight 계산
		- **Q**uery ─ 무엇을 찾을 것인가 
		- **K**ey ─ (이름표(Key)를) 어떻게 찾을 것인가
		- **V**alue ─ (이름표(Key)를 통해서) 찾은 의미 정보
	- 어텐션 헤드 연산 흐름
		1. 유사도 측정 ─ Score(Q,K) = Q⋅K^T
		2. 가중치 분배 ─ Attention Weight 계산 (Softmax로 가중치에 대한 확률 계산)
			- Attention Weights = Softmax(Score) ⇢ Attention Weights의 합은 항상 1 (확률이니까)
			- 가중치를 계속해서 업데이트한다. 관련성이 낮은 것은 계속해서 낮아지게 된다. 합만 1이 될 수 있도록 
		3. 가중합 계산 ─ Context Vector = ∑(Attention Weights×V)
## 트랜스포머 아키텍처
- **목적**
	- S2S 아키텍처 모델의 연산 비효율을 해소하고 이미지나 관계와 같이 의미적인 부분을 잘 파악하기 위해서 사용
	- 층이 많고 블록을 적층할 수 있기 때문에 파라미터가 굉장히 많이 발생 ⇢ 수학적 장치를 내포하고 있음
- **흐름**
	1. 임베딩 변환을 한 꺼번에 입력 (순차적으로 진행하지 않음, 이전 토큰의 정보가 필요하지 않음)
	2. (기존 임베딩 값에 더해서) 위치 인코딩 ─ 위치 신호 합산
		- 주로 sin, cos 함수 이용 (주기성을 갖는 함수)
			- ***e.g.*** 겹치지 않게 하고 방향성을 갖기 위해 짝수는 인덱스 사인, 홀수는 코사인 적용 
	3. **인코더 블록** ─ 인코더 블록은 여러 개를 쌓을 수 있다. 입력 차원과 출력 차원이 동일하므로 적층이 가능하다.
		1. 멀티헤드 어텐션 (Multi Head Attention) 
			- QKV 벡터군을 여러 개 갖고 있음 (단일 벡터군은 셀프 어텐션 ─ 단어 하나당 다른 단어와의 모든 관계)
			- 평가자가 여러 명 있는 것이 중요도를 고르게 판단할 수 있다는 취지에서 사용
			- Attention Weight가 반영된 출력 반환 ─ 맥락을 담고 있는 형태
		2. 밀집층 ─ 앞선 멀티헤드(3개 관점)을들의 결과를 통합해서 결과를 압축한다. 
		3. 드롭아웃 ─ 지나오면서 아주 많은 층을 통과했기 때문에 과적합이 될 수 있으므로 안정화
		4. 잔차연결(값 증폭) ─ 아주 많은 층을 통과했기 때문에 출력이 점점 작아졌으므로 값 증폭 (까먹지 않게)
		5. 층 정규화(값 안정) ─ 잔차연결로 인해 값이 확 커졌기 (불안정) 때문에  다시 정규화로 값 안정 
		6. 이후 피드 포워드 네트워크 (밀집층 + 활성함수(ReLU) + 드롭아웃 + 잔차연결 + 층 정규화) 
	4. **디코더 블록** 
		1. 마스크드 멀티헤드 어텐션 (Masked Multi Head Attention)
			- 맥락을 이미 알고 있으면 다양한 답변을 예측하지 못하거나 알고 있는 맥락이 틀렸을 수 있으므로 
			  현재 정보만 살리고 다음 정보는 마스크를 씌움으로써 (가중치를 0으로 만들어서) 제어
		2. 밀집층 ─ 앞선 마스크드 멀티헤드 어텐션들의 결과를 통합해서 결과를 압축한다. 
		3. 드롭아웃 ─ 지나오면서 아주 많은 층을 통과했기 때문에 과적합이 될 수 있으므로 안정화
		4. 잔차연결(값 증폭) ─ 아주 많은 층을 통과했기 때문에 출력이 점점 작아졌으므로 값 증폭 (까먹지 않게)
		5. 층 정규화(값 안정) ─ 잔차연결로 인해 값이 확 커졌기 (불안정) 때문에  다시 정규화로 값 안정 
		6. 크로스 어텐션 (Cross Attention) 또는 크로스 멀티헤드 어텐션 (Cross Multi Head Attention)
			- 인코더 출력(쿼리)을 이용해서 디코더가 키와 값을 반환. 인코더 + 디코더로 종합하기 때문에 Cross Attention
			- ***cf.*** 쿼리의 출력은 디코더에 있고 맥락 정보만 인코더가 가지고 있다. 디코더는 인코더의 쿼리 벡터를 사용한다.
			- ***cf.*** 크로스 어텐션 단계를 생략하고 생성형으로만 쓰는 경우 ⇢ GPT, Claude 등
		7. 새로운 어텐션이 개입하므로 다시 ─ 밀집층 ⇢ 드롭아웃 ⇢ 잔차연결(값 증폭) ⇢ 층 정규화(값 안정)
		8. 이후 피드 포워드 네트워크 (밀집층 + 활성함수(ReLU) + 드롭아웃 + 잔차연결 + 층 정규화)
## 3. 토막 공부
- 벡터 (방향성) ─ 방향 정보 / 위치와 상관 없이 거리와 방향이 동일하면 동일한 벡터라고 표현 
- 내적 (투영하는 것) ─ 얼마나 비슷한지 측정. cos 함수로 유사도 측정. 포지션과 각도로 위치를 표현할 수 있다.

정확히는 조금 다르게 이해하는 게 맞아.

- **순환층(recurrent layer)이 은닉층에 대응**한다는 건 맞아. MLP의 은닉층 자리에 RNN에서는 순환층이 들어간다고 보면 돼.
- 그런데 **"노드 = 셀"은 아니야.** 셀(cell)은 노드 하나를 가리키는 게 아니라, **매 타임스텝마다 반복 적용되는 하나의 연산 단위** 그 자체를 말해. 즉 순환층을 시간축으로 펼쳤을 때 각 스텝에서 실행되는 계산 블록이 셀이고, 그 셀 하나 안에 은닉 상태의 차원을 구성하는 여러 개의 유닛(노드)들이 들어있어.

그래서 대응 관계를 정리하면:

|MLP|RNN|
|---|---|
|은닉층|순환층|
|은닉층의 노드 개수|셀이 가진 유닛(노드) 개수 = 은닉 상태의 차원|
|—|셀 자체 (타임스텝마다 반복되는 연산 단위)|

예를 들어 Keras의 `SimpleRNN(units=32)`라고 하면, 이 층은 셀 하나로 구성되어 있고 그 셀이 32개의 유닛(노드)을 가지고 있어서 은닉 상태 벡터의 크기가 32가 되는 거야. "셀이 32개 있다"가 아니라 "셀 하나가 32차원 은닉 상태를 만든다"는 뜻이지.

정리하면: **노드/유닛은 셀 안에 포함된 구성 요소**이고, 셀은 그 노드들을 묶어서 타임스텝마다 반복 실행하는 하나의 계산 단위라고 보면 돼.

- **순환층**은 이 전체 구조를 감싸는 개념이야. 하나의 순환층이란 사실 "같은 셀 하나를 타임스텝마다 반복해서 적용한 것"을 말해. 그래서 그림처럼 t-1, t, t+1로 옆으로 펼쳐 놓으면 마치 여러 개처럼 보이지만, 실제로는 **동일한 셀(같은 가중치)이 매 타임스텝마다 재사용**되는 거야.
- **타임스텝**은 그 반복이 일어나는 시점 하나하나. 각 타임스텝마다 셀은 그 시점의 입력(x_t)과 이전 타임스텝에서 넘어온 은닉 상태(h_{t-1})를 받아서, 새 은닉 상태(h_t)를 계산해 다음 타임스텝으로 넘겨줘. 그림의 가로 화살표가 이 흐름이야.
- **셀**은 그 타임스텝 하나에서 실행되는 연산 단위. "입력 + 이전 은닉 상태 → 새 은닉 상태"를 계산하는 수식(가중치 행렬과 활성화 함수)이 들어있는 블록이라고 보면 돼.
- **노드(유닛)**는 셀 안에서 은닉 상태 벡터를 구성하는 개별 원소들. 노드 개수 = 은닉 상태의 차원 수야. 그림에서 셀 안의 파란 점 4개가 "이 셀은 4차원 은닉 상태를 가진다"는 뜻이라고 생각하면 돼.

정리하면 순환층 > (반복되는) 셀 > (그 안의) 노드, 이고 타임스텝은 그 반복이 일어나는 시간축의 단위야.

- **선형결합(가중합)의 결과**는 보통 **순입력(net input)**이라고 부르고, 흔히 zz z로 표기해. zt=Wxxt+Whht−1+bz_t = W_x x_t + W_h h_{t-1} + b zt​=Wx​xt​+Wh​ht−1​+b 이런 식.
- 여기에 **활성화 함수를 적용한 결과**가 바로 **은닉 상태(hidden state)** ht=tanh⁡(zt)h_t = \tanh(z_t) ht​=tanh(zt​) 또는 ReLU(zt)\text{ReLU}(z_t) ReLU(zt​) 같은 형태야.

즉 은닉 상태는 활성화 함수를 통과하기 _전_이 아니라 _통과한 후_의 값을 가리켜. DNN의 일반 은닉층도 똑같은 구조야 — 노드의 선형결합 결과(순입력)에 활성화 함수를 씌운 값이 그 노드의 "출력값"이고, 이 출력값이 다음 층으로 전달되지.

RNN에서 이게 중요한 이유는, 이 활성화 함수를 통과한 은닉 상태 hth_t ht​가 두 군데로 동시에 쓰이기 때문이야:

1. 그 타임스텝의 출력을 만드는 데 쓰이고
2. 다음 타임스텝의 셀로 그대로 넘어가서 다음 순입력 계산에 다시 재료로 쓰여

그래서 정리하면: 선형결합 결과 = 순입력(활성화 전), 그걸 활성화 함수에 통과시킨 결과 = 은닉 상태(활성화 후). 둘을 같은 걸로 부르면 안 돼.

선형결합 자체는 RNN 셀 안에서도 똑같이 일어나. 다만 용어를 좀 더 정확히 짚자면:

- **로짓(logit)**이라는 용어는 보통 **출력층에서 softmax/sigmoid 같은 확률화 함수에 들어가기 직전의 값**을 가리킬 때 주로 써. 즉 "분류 결과를 확률로 바꾸기 전의 원점수"라는 의미가 강해.
- RNN 셀 내부, 즉 은닉 상태를 계산하는 단계에서 나오는 선형결합 값은 로짓이라기보다 **순입력(net input, pre-activation)**이라고 부르는 게 더 정확해. 여기엔 tanh나 ReLU가 씌워지지, softmax가 씌워지는 게 아니니까.

그래서 구조를 다시 정리하면:

- **은닉층/순환층 내부**: 선형결합 → 순입력(pre-activation) → tanh/ReLU 등 활성화 → 은닉 상태
- **출력층**: 선형결합 → 로짓(logit) → softmax/sigmoid → 확률값

즉 "선형결합의 결과"라는 개념 자체는 층마다 똑같이 발생하지만, 그걸 부르는 이름이 **어느 층이냐(은닉층이냐 출력층이냐)**, 그리고 **뒤에 어떤 함수가 붙느냐(활성화 함수냐 확률화 함수냐)**에 따라 순입력 / 로짓으로 갈리는 거야.

실제 관례를 좀 더 정확히 짚으면:

- **선형결합 = 가중합 = 순입력(net input)**: 이 세 개는 거의 동의어로 섞어 써도 무방해. 어느 층이든 Wx+bWx + b Wx+b 형태의 값을 가리키는 표현들이고, 굳이 층을 구분하지 않고 통용돼.
- **로짓(logit)**만은 조금 결이 달라. 이건 원래 **로지스틱 함수의 역함수** (log⁡p1−p\log\frac{p}{1-p} log1−pp​)에서 온 통계학 용어라서, 개념적으로 "확률로 변환되기 직전의 값"이라는 의미가 강해. 그래서 딥러닝 실무·논문에서도 로짓이라는 단어는 **거의 항상 분류기의 출력층, softmax/sigmoid 직전 값**을 가리킬 때만 쓰고, 은닉층 내부의 순입력을 로짓이라고 부르는 경우는 잘 없어.

그러니까 "선형결합=가중합=순입력"까지는 사실상 동의어로 봐도 되는데, 거기에 로짓까지 완전히 같은 자리에 넣기는 애매해. 로짓은 그 중에서도 **"출력층 + 확률화 함수 직전"이라는 위치 정보까지 포함한 특수한 경우**라고 보는 게 더 정확해.

타임스텝은 셀 "안"에 있는 것도 아니고, 셀과 셀 "사이"에 있는 것도 아니야. **타임스텝은 셀이 한 번 통째로 실행되는 단위 그 자체**를 가리켜.

즉:

- 타임스텝 하나 = 셀 전체(선형결합 → 활성화 함수 → 은닉 상태 계산)가 **한 번 완전히 실행되는 것**
- 그 실행이 끝나면 나온 은닉 상태가 다음 타임스텝의 셀 실행에 입력으로 들어감
비유하자면: 타임스텝은 셀이라는 함수를 **몇 번째로 호출했는지 나타내는 순서(인덱스)**이고, 셀은 그 함수 자체(코드)라고 보면 돼. "for문이 3번 도는데, 타임스텝은 그 반복문 안에 있냐 밖에 있냐"라고 묻는 것과 비슷한데 — 타임스텝은 반복문의 "안/밖"이 아니라 **몇 번째 반복인지**를 가리키는 카운터인 거지.

셀 자체가 "선형결합 → 활성화 함수 → 은닉 상태 계산"까지 포함하는 하나의 연산 단위이고, 타임스텝은 그 셀이 한 번 통째로 실행되는 걸 가리킨다고 했잖아. 그러니까 셀이 실행될 때마다 그 안에 포함된 활성화 함수도 당연히 같이 실행돼.

정리하면:

- 타임스텝 t마다: zt=Wxxt+Whht−1+bz_t = W_x x_t + W_h h_{t-1} + b zt​=Wx​xt​+Wh​ht−1​+b (선형결합) → ht=tanh⁡(zt)h_t = \tanh(z_t) ht​=tanh(zt​) (활성화 함수 적용)
- 이 과정이 t=1, 2, 3, ... 매 타임스텝마다 반복

즉 활성화 함수는 셀이 실행되는 횟수만큼, 다시 말해 **타임스텝 개수만큼 매번 적용**되는 거야. 다만 매번 적용되는 활성화 함수 자체(tanh든 ReLU든)와 그 파라미터(선형결합에 쓰이는 가중치)는 모든 타임스텝에서 동일해 — 셀 자체가 재사용되는 거니까 활성화 함수도 "같은 함수가 반복 호출"되는 거지, 타임스텝마다 다른 활성화 함수가 쓰이는 게 아니야.

둘 다 "가중치"라는 점에서는 같아. 다만 쓰이는 역할이 달라서 구분해서 부르는 것뿐이야.

**임베딩 가중치**: 이것도 사실 수학적으로는 완전히 똑같은 가중치 행렬이야. 임베딩 층은 사실 "단어를 원-핫 벡터로 표현한 뒤, 그 원-핫 벡터에 가중치 행렬을 곱하는 것"과 동일한 연산이거든. 다만 원-핫 벡터를 곱하면 결과적으로 그 행렬에서 해당 단어에 대응하는 행(row) 하나만 그대로 뽑아오는 것과 같아서, 실제 구현에서는 행렬곱 대신 "룩업 테이블에서 찾아오기"로 처리해. 그래서 임베딩 가중치는 이름은 다르지만 본질은 **(단어 개수) × (임베딩 차원) 크기의 가중치 행렬**이야.

**셀의 가중치**: 이건 우리가 지금까지 얘기한 선형결합 Wxxt+Whht−1+bW_x x_t + W_h h_{t-1} + b Wx​xt​+Wh​ht−1​+b에 쓰이는, 네가 일반적으로 이해하는 그 가중치 맞아. 입력과 이전 은닉 상태를 새로운 은닉 상태로 변환하는 역할을 해.

정리하면:

||임베딩 가중치|셀의 가중치|
|---|---|---|
|수학적 본질|가중치 행렬 (동일)|가중치 행렬 (동일)|
|역할|이산적인 단어(인덱스)를 연속적인 벡터로 변환|입력+이전 은닉상태를 새 은닉상태로 변환|
|실무상 동작|룩업 테이블처럼 동작|실제 행렬곱 연산 수행|

**임베딩층 (순환층보다 먼저) → 순환층 → (그 안에서 시퀀스 길이만큼 반복되는) 셀 → (셀 안의) 노드/게이트**

- 임베딩층: 입력(토큰 ID)을 벡터로 변환. 순환층에 들어가기 **전** 단계.
- 순환층(RNN/LSTM): 임베딩된 벡터 시퀀스를 입력받아 처리하는 층 자체.
- 셀: 순환층 안에서 타임스텝마다 반복 실행되는 단위 (시퀀스 길이만큼 셀이 펼쳐짐, 근데 실제로는 같은 셀이 재사용됨 — weight sharing).
- 노드: 셀 내부의 뉴런/게이트 (LSTM이면 forget gate, input gate, output gate, cell state 등을 구성하는 단위들).

# 데일리 퀘스트
### 1번 문항

- **Q.** Seq2Seq 모델에서 인코더가 디코더에 전달하는 '컨텍스트 벡터'의 내부 구성 요소로 옳은 것은?
- **A.** LSTM 인코더의 마지막 시점 은닉 상태(h_T)와 셀 상태(c_T) 튜플 세트
- *LSTM은 단기 기억(은닉 상태)과 장기 기억(셀 상태)을 함께 유지하므로, 인코더가 압축한 컨텍스트 벡터도 이 두 상태를 튜플로 묶어 디코더에 전달*
### 2번 문항

- **Q.** 디코더 학습 시, 이전 시점의 예측값 대신 실제 정답 단어를 다음 시점 입력으로 강제 주입하여 학습을 안정화하는 기법의 명칭을 쓰시오.
- **A.** 교사강요기법
- *교사 강요는 학습 초기 디코더의 잘못된 예측이 연쇄적으로 이어지는 것을 막고 수렴 속도를 높이기 위해 실제 정답을 다음 입력으로 주입하는 기법*
### 3번 문항

- **Q.** 어텐션 메커니즘에서 디코더의 현재 상태 벡터에 해당하며, 정보를 탐색하기 위한 '질문' 역할을 하는 요소는?
- **A.** Query
 - *Query는 현재 시점에서 정보를 찾고자 하는 주체인 디코더의 상태 벡터. Key는 비교 대상이 되는 이름표, Value는 실제 의미 정보이며, Bias는 어텐션 구성요소가 아님*
### 4번 문항

- **Q.** Seq2Seq 모델과 비교했을 때, 트랜스포머(Transformer)가 채택한 설계 철학으로 옳은 것은?
- **A.** RNN 구조를 완전히 배제하고 어텐션만으로 병렬 연산 구조를 설계했다
- *트랜스포머는 RNN의 순차 처리로 인한 속도 한계를 극복하기 위해 순환 구조를 없애고 셀프 어텐션 기반의 병렬 처리 구조를 채택*
### 5번 문항

- **Q.** 트랜스포머 디코더에서 학습 시 미래의 정답 단어를 미리 참조하지 못하도록 차단하는 기법의 이름은?
- **A.** 패딩 마스킹(Padding Masking) **(오답)**
- *인과적 마스킹은 하삼각행렬 형태의 마스크를 적용해 미래 시점의 단어 정보를 무한대로 만들어 소프트맥스 확률을 0으로 만들어 컨닝을 방지. 패딩 마스킹은 의미 없는 패딩 토큰을 무시하는 용도이고, 위치 인코딩과 층 정규화는 각각 순서 정보 부여와 값 안정화를 위한 별개의 기법*
