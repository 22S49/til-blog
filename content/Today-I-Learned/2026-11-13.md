# RAG 메타데이터

- 청크 본문(`page_content`) 옆에 붙는 꼬리표 딕셔너리 ─ source, department, version, …
- 검색에는 쓰이지 않고, 본문이 어느 문서에서 왔는지 추적하는 용도
```
file_info(dict) ──▶ Document(page_content, metadata)
                      │ split_documents   (메타데이터가 각 청크로 복사됨)
                      ▼
                  청크들 ──▶ 벡터저장소 ──▶ retriever 검색
                                              ▼
                                      doc.page_content   → {context}
                                      doc.metadata[...]  → {dept}, {source}
                                              ▼
                                           prompt ──▶ model ──▶ 답변 + 출처
```
## 출처 명시 RAG

- 역할은 한 줄로 작성하고 (길게 쓰면 규칙이 묻힘) 규칙을 번호 또는 문단으로 구분한다. 
- 환각을 줄이기 위해 출력 형식에 예시와 모를 떄의 답변 양식을 지정한다. 
	- 대괄호 등으로 머리말을 구분해서 자료와 지시를 분리해서 문서 안의 문장을 지시로 착각하는 걸 방지한다.
- 규칙은 system 에만 두고 유저 메세지는 user 영역에 둔다. 
```python
prompt = ChatPromptTemplate.from_messages([
    ('system', (
        # 1) 역할
        '당신은 쇼핑몰 고객센터 상담원입니다.\n\n'

        # 2) 규칙
        '[규칙]\n'
        '1. 반드시 [참고문서]의 내용에만 근거해 답변하세요.\n'
        '2. [참고문서]에 없는 내용은 추측하지 말고 "잘 모르겠습니다."라고만 답하세요.\n'
        '3. 답변은 3문장 이내로 간결하게 작성하세요.\n'
        '4. 답변 맨 끝 줄에는 아래 [출처 표기]를 그대로 붙이세요.\n\n'

        # 3) 출처 표기: 변수가 채워진 문구를 모델이 그대로 복사하게 함
        '[출처 표기]\n'
        '[출처: {category}({source})]\n\n'

        # 4) 출력 예시: 형식만 보여주고, 출처 줄은 위와 같은 변수를 재사용
        '[출력 예시]\n'
        '구매 후 7일 이내에만 환불이 가능합니다.\n'
        '[출처: {category}({source})]\n\n'

        # 5) 참고 자료
        '[참고문서]\n{context}'
    )),
    ('user', '{question}'),
])

response = chain.invoke({
    'context': docs.page_content, # 청킹된 문서
    'category': docs.metadata['category'],
    'source': docs.metadata['source'],
    'question': user_query,
})
```
# RAG 인덱싱을 위한 문서 로딩
## 0. 문서 전처리
```python
# 사용 모듈 : re, bs4, PyMuPDFLoader, WebBaseLoader, RecursiveCharacterTextSplitter

# 이번 예제에서는 청커를 한 번만 만들어서 PDF/웹에 같이 사용
rec_splitter = RecursiveCharacterTextSplitter(chunk_size=100, chunk_overlap=20)

# 줄바꿈, 탭, \xa0 등 연속 공백을 한 칸으로 정리
def clean(text):
    return re.sub(r'\s+', ' ', text).strip()
```
## 1. PDF 문서 로딩
```python 
# PDF는 페이지 1장 = Document 1개 (metadata에 page, source 등이 자동으로 들어감)
pdf_documents = PyMuPDFLoader(file_path='docu.pdf').load()

# PDF 줄 끝의 \n 제거
for doc in pdf_documents:
    doc.page_content = clean(doc.page_content)   

# 출처 표시에 쓸 키 확인: source(파일명), page(0부터 시작하는 쪽 번호) 등
print(pdf_documents[0].metadata)

# metadata는 각 청크로 복사됨
pdf_docs = rec_splitter.split_documents(pdf_documents)   
```
## 2. 웹 문서 로딩
```python 
target_url = 'https://www.yonhapnewstv.co.kr/news/AKR20261113115501956'

# 웹 페이지의 본문만 로드하기 위해 메타데이터용 객체를 만든다.
# {'source': URL, 'title': '기사 제목', 'description': '요약', 'language': 'ko'}
meta_doc = WebBaseLoader(web_path=target_url).load()

web_loader = WebBaseLoader(
    web_path=target_url,
    # id="articleBody" 영역(기사 본문)만 파싱 → 메뉴, 광고, 로그인 문구 제외
    bs_kwargs={'parse_only': bs4.SoupStrainer(id='articleBody')},
    # 태그 경계마다 공백을 넣어 "습니다.이 계획"처럼 문장이 붙는 것을 방지
    bs_get_text_kwargs={'separator': ' ', 'strip': True},
)
web_documents = web_loader.load()

for doc in web_documents:
    # 공백 정리 후, 기사 끝의 제보 안내/저작권/해시태그는 잘라냄
    doc.page_content = clean(doc.page_content).split('뉴스기사문의')[0].strip()

# 웹은 URL 하나 = Document 1개
print(web_documents[0].metadata)   # source만 있음 (본문만 파싱해서 title은 비어 있음)

# metadata는 각 청크로 복사됨 → 페이지 하나이기 때문에 모든 청크가 같은 메타데이터를 갖음
web_docs = rec_splitter.split_documents(web_documents)
```

> [!NOTE] **USER_AGENT 환경변수가 없는 경우 발생하는 WebBaseLoader 경고** 
> - WebBaseLoader는 환경변수 USER_AGENT가 없으면 동작은 하지만 경고 알림 발생
> 	- `USER_AGENT environment variable not set` 
> - 일부 사이트는 User-Agent가 없거나 수상한 요청을 차단할 수 있어서, 환경변수(이름)를 넣는 게 안전
> - 로더는 import될 때 환경변수를 읽기 때문에 langchain_community import보다 먼저 설정해야 하고
> - `USER_AGENT` 환경변수 값은 요청 헤더로 사이트에 전달되므로 개인정보를 넣으면 안 된다. 
> - 예제 코드 ─ `os.environ['USER_AGENT'] = 'rag-study'`
