### 연습장
#### 단층 퍼셉트론 (단층 신경망)
- 모델 파라미터 개수 = 총 가중치 수 + 총 절편 수
	- 총 가중치 수 = 특성 수 × 클래스 수
	- 총 절편 수 = 클래스 수
- 입력층에서 바로 출력층으로 작용 — 단층 퍼셉트론 (은닉층 없음)
- 입력층 ⇢ 선형결합(로짓) 출력 ⇢ 활성화 함수 ⇢ 확률(분포) 출력
	- 로짓 출력을 출력층으로 보기도 하고, 활성화 함수까지를 출력층으로 보기도 한다. 
- 활성화 함수를 왜 쓰나요?
	- 선형결합을 비선형으로 변환해서 복잡한 문제를 풀기 위해 (복잡한 관계 표현)
	- 선형이면 영원히 오차를 줄일 수 없는데 비선형으로 비틀면 오차를 줄일 수 있다. 
#### 로지스틱 회귀 모델
- 선형 회귀 방식을 이용한 **분류** 모델 — 로지스틱 *회귀 모델*이라고 하지만 사실은 **분류** 모델
	- 선형 회귀 + 활성화 함수 = 로지스틱 회귀 분류 모델
	- cf. 사이킷런의 LogisticRegresstion은 L2 규제가 기본값으로 설정되어 있음
		- 순수한(규제 없는) 결과는 penalty=None으로 명시적으로 적용해주어야 함

|                              | 선형 회귀                                        | 로지스틱 회귀                                            |
| ---------------------------- | -------------------------------------------- | -------------------------------------------------- |
| 개념 배경                        | 거리                                           | 확률                                                 |
| 확률 오차<br>(오차항)               | 정규분포 가정                                      | 정규분포 불가                                            |
| 정답 레이블(y)                    | 정규분포 추종 (연속)                                 | 베르누이 분포 추종 (이산)                                    |
| 손실 함수                        | MSE (평균제곱오차)<br>MAE (평균절대오차)                 | Likelihood (가능도, 확률밀도)<br>CrossEntropy (음의 로그 가능도) |
| 모델 파라미터 추정<br>(weight, bias) | 최소제곱(LSE) 추정<br>* 방향: 최소값<br>— 거리가 가까워야 하니까! | 최대우도(MLE) 추정<br>* 방향: 최대값<br>— 확률이 높아야 하니까!        |
| 예측 레이블(y_hat)                | 선형결합 = 출력<br>(출력값은 무한대 발산)                   | 선형결합(로짓) ⇢ 활성화 함수 ⇢ 출력<br>(출력값을 확률로 압축)<br>        |

> [!warning] 선형결합 = 가중합 = 원시점수 = 로짓은 관용적 용어 사용일뿐 엄밀히 따지면 오즈의 로그값과는 다름
> - 선형결합 = 가중합 = 원시점수 — 모든 층에서 입력 또는 출력(다음 층에 입력되는 값)값을 지칭
> - 로짓(Logit) — 오즈비(odds ratio)의 자연로그
> 	- 로지스틱 회귀모델에서 선형 에측식(모델 파라미터)을 구성하는 항
> 	- 활성화 함수에 입력되기 직전의 값 ⇢ *보통 출력층(softmax, sigmoid) 직전 값을 가리킬 때 사용*
> 		- 이 순간만큼은 선형결합 = 가중합 = 원시점수 = 로짓으로 관용적 사용이 가능한 것
> - 오즈(odds) — 성공 확률을 p로 정의할 때, 실패 대비 성공 확률의 비율

> [!NOTE] 통계학과 머신러닝(딥러닝)의 선호도 관점에서 가능도와 크로스엔트로피 살펴보기
> - 통계학에서는 확률을 최대화하는 것을 좋아한다. ⇢ 가능도 개념으로 설명
> - 머신러닝(딥러닝)에서는 손실(Loss)을 최소화하는 것을 좋아한다. 
> 	- 머신러닝(딥러닝)은 경사하강법 알고리즘으로 설계 ⇢ 크로스엔트로피 개념으로 설명
> - 종합하면 — 가능도 최대화 = 로그 가능도 최대화(최대우도추정) = 크로스엔트로피 최소화

> [!NOTE] 선형 회귀에서의 활성화 함수
> - 선형 회귀는 활성화 함수가 없는 것이 아니라 활성화 함수로 항등함수(f(x)=x, 선형)를 쓴다. 
> 	- 반면에 로지스틱 회귀는 시그모이드, 소프트맥스 등 비선형 활성화 함수를 쓴다.
> 	- 아울러 은닉층에서도 시그모이드, 렐루 등 비선형 활성화 함수를 쓴다. 
> - 활성화 함수가 항등함수이기 때문에 (선형 활성화 함수이기 때문에) 입력값을 그대로 통과시키므로 
>   활성화 함수가 없다, 또는 활성화 함수를 생략한다고 관례적으로 표현한다.

##### 이진 분류 — 2가지 2가지 종류(class) 분류
- 이산형
	- **활성화 함수** — 시그모이드 함수 (0~1)
		$$f(x) = \frac{1}{1 + e^{-x}} = \frac{e^{x}}{e^{x}+1}$$
		- 로짓 함수의 역함수 ⇢ 로짓을 받아서 **확률**을 출력한다. 기준 확률에 따라 분류한다.
		- e — 자연상수, 오일러 수 
		- x — 입력값이 클수록 1에 가까워지고 입력값이 작을 수록 0에 가까워진다. ⇢ 0과 1사이로 압축
		- cf. 시그모이드 함수의 파생 — 로지스틱 함수, 쌍곡탄젠트 함수, 아크탄젠트 함수, 오차 함수, …
			- 따라서 로지스틱 회귀 모델 != 로지스틱 함수 
	- **손실 함수** — BCE(Binary Cross Entropy)
		$$L = -[y \log(\hat{y}) + (1 - y) \log(1 - \hat{y})]$$
		
		- log(1) = 0, log(0) = ∞ 라는 원리를 이용 
			- 실제값과 예측값이 다르다 (오차가 크다) = log(0) = 손실(Loss)이 무한에 가깝게 도달 
			- 실제값과 예측값이 같다 (오차가 작다) = log(1) = 손실(Loss)이 0에 가깝게 도달
##### 다중 분류 — 3가지 이상 종류(class) 분류
- 범주형
	- **활성화 함수** — 소프트맥스 함수 (각 클래스별 확률의 총합이 1)
		$$\sigma(\mathbf{z})_i = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}$$
			
		- 정답 배열(원-핫 인코딩)을 받아서 **확률**을 출력한다. 
			- 정수형 레이블을 받으면 수치적 편향성이 발생할 수 있으므로 원-핫 인코딩 필요
				- e.g. 0, 1, 2 ⇢ \[1, 0, 0], \[0, 1, 0], \[0, 0, 1] 
			- 원-핫 인코딩에서 분류 개수가 많아지면 
				- 메모리가 부족해 진다. 연산량이 많아진다. 모델 성능이 떨어진다. 
				- 다중공선성이 높아진다. 차원수가 많아져 정보의 밀도가 옅어진다.
	- **손실 함수** — CCE(Categorical Cross Entropy)
		$$L = - \sum_{c=1}^{C} y_c \log(\hat{y}_c)$$
		
		- log를 취하기 때문에 정답이면 손실을 적게 주고 정답이 아니면 손실을 크게 준다. 
		- 손실을 구하기 위해서는 반드시 원-핫 인코딩이 선행되어야 한다.
- 희소 범주형
	- **활성화 함수** — 소프트맥스 함수 (각 클래스별 확률의 총합이 1)
		- 정수형 레이블을 받아서 **확률분포**을 출력한다. 수치적 편향성은 내부적으로 처리한다.
		- 내부적으로 정답 레이블의 인덱스를 확률로 계산한다. = 임베딩 레이어를 품고 있다.
		- 확률분포 = 실수 밀집 벡터
	- **손실 함수** — SCCE(Sparse Categorical Cross Entropy)
		$$L = - \log(\hat{y}_{target})$$
		- target = index
		- log(1) = 0, log(0) = ∞ 라는 원리를 이용 
			- 실제값과 예측값이 다르다 (오차가 크다) = log(0) = 손실(Loss)이 무한에 가깝게 도달 
			- 실제값과 예측값이 같다 (오차가 작다) = log(1) = 손실(Loss)이 0에 가깝게 도달
#### K-Fold 교차 검증
- 골고루 학습할 수 있도록 훈련 세트를 나눠서 (K개 그룹으로 데이터를 나눠서) 훈련하고 그룹간 검증
- 각 그룹의 정확도 평균과 테스트 세트의 정확도를 비교 검증하는 방법 (회귀, 분류모델에서 모두 사용 가능)
	- 훈련 데이터 안에서 fold를 돌아가면서 검증하기 때문에 
		- K-Fold를 쓰고자 할 경우에는 고정된 별도 검증 데이터를 분리할 필요가 없다.
	- 그렇다고 분류 전용 기법은 아님!
- K-Fold 교차 검증을 통한 직관
	- 단일 모델에 대한 판단
		- fold별 점수가 비슷하면 — 모델이 어떤 데이터로 학습하든 안정적으로 비슷한 성능을 낸다.
		- fold별 점수가 산발하면 — 모델이 특정 데이터 부분집합에 민감하게 작용한다. 
			- 과적합 경향 의심 — train fold와 validation fold 성능을 추가로 확인한다.
			- 데이터 자체에 이상치 또는 특정 구간에 노이즈가 몰려 있는 것으로 의심
			- 데이터 자체의 규모가 작아서 어떤 fold를 구성해도 대표성이 떨어지는 경향 의심
	- 여러 모델에 대한 판단
		- 모델A의 정확도 평균이 모델B의 정확도 평균보다 높더라도 모델A가 무조건 낫다고 할 수 없다.
		- 각 모델의 fold별 정확도 분산을 보고 정확도를 신뢰할 수 있는지 더 살펴봐야 할 수도 있다. 
- cf. 최적의 하이퍼 파라미터 선택 — GridSearch
	-  하이퍼 파라미터 조합의 성능 평가는 내부적으로 K-Fold 교차검증으로 수행하고 선택한다.
#### Copy-on-Write(CoW)
- 파이썬 3.0 버전 이후부터는 Copy-on-Write(CoW)가 원칙
	- CoW 규칙 — 어떤 서브셋이든 무조건 원본의 copy처럼 동작한다는 규칙
	- CoW 규칙은 슬라이싱이나 파생 연산, 불리언 연산 등일 때 적용 (굳이 .copy() 안 해도 됨)
- 단, 똑같은 변수를 재할당하는 단순 할당(e.g. df2 = df1)은 여전히 참조이기 때문에 깊은 복사 필요
#### stratify 옵션
- 특정 클래스가 한 쪽에 쏠리면 학습이나 평가가 왜곡될 수 있기 때문에 층화추출
	- 데이터 분할 시, 원본 데이터의 클래스 비율을 train, test에 그대로 유지하기 위한 옵션
- 회귀보다 분류 모델에 더 유용하게 작용
#### 다층 퍼셉트론 (다층 신경망 : MLP)
- 모델 파라미터 개수 
  = (입력층~은닉층 구간의 총 가중치 수 + 총 절편 수) + (은닉층~출력층 구간의 총 가중치 + 총 절편 수)
	- 총 가중치 수 = (입력층인 경우 특성 수, 은닉층인 경우 은닉층 수) × (은닉층 수 또는 출력층 수)
	- 총 절편 수 = 은닉층 수 또는 출력층 수
	- e.g. 특성 4개, 은닉층이 5개, 클래스  3개인 경우 총 모델 파라미터 수 — 43개
		- {(4 × 5) + 5} + {(5 × 3) + 3} = 43
- 입력층 ⇢ 선형결합(가중합) ⇢ 활성화 함수 ⇢ 은닉층 출력 ⇢ 선형결합(로짓) ⇢ 활성화 함수 ⇢ 출력층 출력
	- 은닉층이 여러 개인 경우, 은닉층이 출력층이자 입력층의 역할이 된다. (연쇄 작용)
	- 단순하게 은닉층이 많다고 해서 예측을 잘 하는 것은 아니다. 
		- 가중치가 추가된다고 해서 예측이 잘 되는 건 아니다. 
		- 은닉층이 단순히 새로운 파라미터에 불과 (선형결합에 불과 ⇢ 오차를 줄이기 위한 비선형화 필요)
		- 모델이 오차를 줄이기 위해 구불거리게 될 수 있도록 해줘야 하고 그 역할을 활성화 함수가 하는 셈
		- 층이 많아질 수록 메모리 소모도 크므로 결과의 효율성과 과적합, 다중공선성 등을 경계해야 함
- 은닉층의 활성화 함수
	- 은닉층의 활성화 함수는 출력층의 활성화 함수와 달리 확률화 함수 개념이 아니므로
	  선형결합결과를 로짓으로 지칭할 수 없다. (로짓의 의미는 확률로 변환되기 직전의 값이기 때문)
	- 시그모이드(Sigmoid)
		- 0~1로 압축하기 때문에 층이 많아질 수록 파라미터가 점점 작아지기 때문에 기울기도 작아진다.
			- 결국 가중치 업데이트가 미미해진다. ⇢ 학습이 이루어지지 않는다. ⇢ 기울기가 소실된다. 
			- 최근에는 은닉층 활성화 함수로 시그모이드를 거의 사용하지 않는다. 
	- 렐루(ReLU)
		- 음수는 0, 양수는 그대로 통과시킨다. 
		- 입력값이 계속 음수여서 0만 출력하는 죽은 뉴런(Dead ReLU) 현상이 발생할 수 있다.
### 데일리퀘스트
#### 1번 문항
- **Q**. 선형 회귀와 로지스틱 회귀의 관계에 대한 설명으로 가장 올바른 것은?
- **A**. 로지스틱 회귀는 선형 회귀의 출력값을 활성화 함수로 0과 1 사이 확률로 변환하여 분류를 수행한다.
- *로지스틱 회귀는 선형 회귀로 raw score(z)를 계산한 뒤 활성화 함수를 통해 0~1 사이 확률값으로 변환하여 분류 문제를 해결합니다.*
#### 2번 문항
- **Q**. 이진 분류와 다중 분류에서 사용하는 활성화 함수를 올바르게 짝지은 것은?
- **A**. 이진 분류: 시그모이드 / 다중 분류: 소프트맥스
- *이진 크로스 엔트로피(BCE)는 시그모이드를 출력층 활성화 함수로 사용하고, 범주형/희소 범주형 크로스 엔트로피(CCE/SCCE)는 소프트맥스를 사용합니다.*
#### 3번 문항
- **Q**. 정답 레이블이 원-핫 인코딩이 아닌 정수형(예: 0, 1, 2)으로 되어 있을 때 메모리 효율을 위해 사용하는, 다중 분류용 손실 함수의 이름은 무엇일까요?
- **A**. SCCE
- *SCCE(희소 범주형 크로스 엔트로피)는 정수형 레이블을 그대로 사용해 정답 인덱스의 확률값만 추출하여 연산하므로 원-핫 배열 생성 없이 메모리를 절약할 수 있습니다.*
#### 4번 문항
- **Q**. K-Fold 교차 검증을 수행하기 전에 데이터를 반드시 Shuffle(섞기)해야 하는 이유로 가장 적절한 것은?
- **A**. 데이터가 품종별로 순서대로 정렬되어 있을 경우, 특정 Fold에 한 클래스만 몰리는 불균형이 발생할 수 있기 때문이다.
- *순서대로 정렬되어 있을 때 섞지 않고 Fold를 나누면 특정 조각에 한 품종만 100% 몰리는 불균형 시험지가 만들어질 수 있습니다.*
#### 5번 문항
- **Q**. 범주형 데이터를 1, 2, 3처럼 단순 정수(레이블 인코딩)로 변환하지 않고, 각 범주에 독립된 열을 만들어 해당 열만 1로 표시하는 전처리 방식을 무엇이라고 할까요?
- **A**. 원핫 인코딩
- *원핫 인코딩은 범주 간에 서열이나 크기 관계가 없음에도 정수로 변환할 때 생기는 수치적 편향성 문제를 해결하기 위해, 모든 범주에 독립된 열을 부여하고 해당하는 열만 1로 표시하는 전처리 기법입니다.*
