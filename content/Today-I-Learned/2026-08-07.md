#### 파이썬의 기본 자료형 (Primitive data Types)
- 자료
	- 연산을 위해 필요한 값, 데이터
- 자료형
	- 개념
		- 데이터의 유형, 테이터의 종류
		- 일반적으로 동적 타이핑이므로 값에 따라 알아서 자료형 지정
	- 분류
		- 숫자형 — 정수(int), 실수(float)
		- 문자형 — 문자 또는 문장('str) 
			- ' ' 또는 " " 형태로 선언
			- 여러 줄이 필요할 때는 """…""" 형태로 선언
		- 논리형 — 참(True), 거짓(False) — 조건문 등에 판별을 위해 사용
			- True
				- 명시적으로 참인 경우
				- 값이 존재하는 상태
					- 0이 아닌 숫자, 글자가 포함된 문자열, 요소가 채워진 리스트 등
			- False
				- 명시적으로 거짓인 경우
				- 값이 존재하지 않는 상태 (비어있는 상태)
					- 숫자 0, 빈 문자열 "", 빈 리스트 \[], 데이터가 없음을 뜻하는 None 등
		- None Type
			- 변수만 선언하고 싶을 때 일단 None 값 대입
			- 변수만 선언할 경우 NameError 오류 발생하니까 (파이썬 특징) 
#### 명시적 형변환 (Explicit Type Conversion)
- 연산은 같은 자료형끼리 가능한 것이 원칙
- 형변환 함수
	- 단일 값(스칼라 변수)에 대해 적용
		- \[번외] 시리즈, DF, 배열 등에서의 형변환(벡터화)
			- astype(…)
			![[astype_tonumeric_차이.png]]
	- int(…) — 정수형로 변환
	- float(…) — 실수형로 변환
	- bool(…) — True, False 변환
	- str(…) — 문자형으로 변환
#### 묵시적 형변환(Implicit Type Conversion)
- 숫자형 연산 시, 자료 유실이 없는 자료형으로 자동 변환
	- e.g. 정수형+실수형=실수형
```python
num1 = 100
num2 = 3.123
type(num1), type(num2) # (int, float)

num3 = num1 + num2 # num1 자료형 묵시적 형변환(int⇢float)
num3, type(num3) # (103.123, float)

num3 = num1 + int(num2) 
num3, type(num3) # (103, int)
```
#### 형변환 시 주의해야 할 예외와 에러(value Error)
```python
time = "10시"
int(time) # 'ValueError: invalid literal for int() with base 10: '10시''
if time.isdigit():
	int(time) + 1 # 이상 없음
```
#### 항과 연산자
- 항 — 연산에 사용되는 값
- 연산자 — 연산에 사용되는 기호
#### 연산자의 종류
- 대입
	- =
	- 모든 연산자 중에서 우선순위가 가장 낮음 (가장 마지막에 연산됨)
- 산술 (우선순위순 나열)
	- \*\*, \*, /, //, %, +, -
	- 연산결과 — 수치
	- 소괄호로 묶인 연산에 대해 강제 우선순위 적용할 수 있음
- 비교
	- >, >=, <, <=, \==, !=, is
	- 연산결과 — 참, 거짓
	- 판별, 조건, 반복문에서 자주 사용, 비교 연산이 논리 연산보다 먼저 연산됨
- 논리
	- and
		- 각 항이 모두 True ⇢ True
		- 각 항에 하나라도 False ⇢ False
	- or
		- 각 항에 하나라도 True ⇢ True
		- 각 항이 모두 False ⇢ False
	- not
		- True 조건을 False 조건으로 반전
		- False 조건을 True 조건으로 반전
		- e.g. `not (result1 and result2)`
- 복합 대입
	- +=, -=, \*=, /=, //=, %=
	- 대입 연산자를 다른 연산자(주로 산술 연산자)와 결합해서 사용
	- 다항 연산을 단항 연산으로 바꾸어 표현할 수 있음
- 부호 반전
	- 음수 ⇢ 양수, 양수 ⇢ 음수
```python
num = 100
-num # -100
--num # 100
---num # -100
```
#### 동일성 vs. 동등성
- 동일성(is)
	- 동일한 대상을 비교
	- 엄격한 일치, 값과 자료형, 주소 모두 비교
- 동등성(\==)
	- 동일한 가치를 비교
	- 느슨한 일치, 값만 비교
```python
num1 = 1000
num2 = 1000
num1 == num2, num1 is num2 # (True, False)

num3 = num1
num3 is num1 # True
```
#### 연산자 우선순위
- 대입 < 논리 < 비교 < 산술 < 소괄호
#### 단락 회로 평가(Short-Circuit Evaluation)
- 논리연산을 할 때 답이 먼저 나오면 다음 연산을 하지 않고 답이 안 나왔다면 다음 연산을 진행
- 예시
```python
True or 10**2 # True — 이미 답(True)이 나왔으므로 다음 연산(10**2)을 하지 않음
False or 10**2 # 100 — 답이 없으므로(False) 다음 연산(10**2)하여 답을 결정

False and 10**2 # False — 이미 답(False)가 나왔으므로 다음 연산(10**2)을 하지 않음
True and 10**2 # 100 — 답(True)을 확정하려면 다음 연산(10**2)까지 가야 하므로 연산
```
##### or 연산을 이용한 기본값 설정 (비어 있을 때 대체되는 값 설정)
```python
message = ""
message or "기본 메세지" # '기본메세지'
```
##### and 연산을 이용한 조건 처리
```python
height = 165
height >= 160 and "크다" # '크다'
```
#### 문자열 형식화
- 템플릿화, formatting
- 문자열 = 단어 (문자가 열지어 있는 것)
#### % 연산자 방식
- %s — 문자열
	- %숫자s — 최소 숫자 자리 수만큼 공간 차지, 남는 공간은 공백
- %d — 정수
	- %{대체숫자}숫자d — 최소 숫자 자리 수만큼 공간 차지, 남은 공간은 대체숫자로 채움
	- 실수를 정수 문자열 형식에 대입하는 경우 정수 문자열로 반환
		- 그럼 소수점이 날아가니까 정수인지 실수인지 잘 모르겠을 때 (예측 불가 할 때) %s 사용
- %f — 실수
	- %.2f — 소수점 둘째 자리까지 표시 (셋째 자리 내림)
	- %10.2f — 정수부는 7자리, 소수부는 2자리까지 표시 (셋째 자리 버림) (온점을 포함해서 10자리)
	- %010.2f — 정수부는 7자리, 소수부는 2자리까지 표시하고 공간은 0으로 채움
- 예시
```python
message = "나의 이름은 %s이고 나이는 만 %d세입니다."
message % ("철수", 20) # '나의 이름은 철수이고 나이는 만 20세입니다.'
```
#### str.format() 메서드 방식
- 순서 지정 교체: 중괄호로 순서 지정 후 교체 — 이 때, 순서는 정의된 것이 아니라 인덱스
```python
message = "내 이름은 {0}이고 나이는 {1}입니다."
message.format("철수", 20) # '내 이름은 철수이고 나이는 20입니다.'
```
- 단어 지정 교체: 중괄호로 단어 지정 후 교체
```python
message = "내 이름은 {name}이고 나이는 {age}입니다."
message.format(name="철수", age=20) # '내 이름은 철수이고 나이는 20입니다.'
```
- 순서 단어 혼합 지정: 반드시 숫자 자료형을 먼저 써야 함
```python
message = "내 이름은 {name}이고 나이는 {0}입니다."
message.format(20, name="철수") # '내 이름은 철수이고 나이는 20입니다.'
```
#### f-string 방식
```python
name = "영희"
age = 20
f"내 이름은 {name}이고 {age}입니다." #' 내 이름은 영희이고 나이는 20입니다.'
```
```python
price = 10000
f"가격: {price:>10,}" # '가격:     10,000'
f"가격: {price:<10,}" # '가격: 10,000    '
f"{price=}" # 디버깅 조절자, 'price=10000'
```

### 오늘의 퀘스트
#### 1번 문항
- **Q**. 파이썬에서 x = 7, y = 3일 때, x % y 연산을 수행한 결과값으로 올바른 것은 무엇인가요?
- **A**. 1
- *% 연산자는 나눗셈 후 남은 나머지를 반환합니다. 7을 3으로 나누면 몫은 2이고 나머지는 1이므로 정답은 1입니다. 2는 몫(//) 연산 결과이며, 2.333...은 일반 나눗셈(/) 결과, 21은 곱셈(\*) 결과에 해당합니다.*
#### 2번 문항
- **Q**. 논리 연산(and, or)에서 왼쪽 항의 결과만으로 전체 식의 참/거짓이 이미 확정되면, 오른쪽 항의 계산을 건너뛰는 파이썬의 연산 최적화 방식을 무엇이라 부르나요?
- **A**. 단락회로평가
- *and 연산은 좌측이 False이면, or 연산은 좌측이 True이면 우측 항을 평가하지 않고 즉시 결과를 확정합니다. 이를 단락 회로 평가라고 하며, 불필요한 연산을 줄이고 에러(예: ZeroDivisionError)를 방지하는 효과가 있습니다. (수치를 맞추는 것이 목적이 아니라 판별이 목적이므로, 판별이 완료되면 끝나는 셈)*
#### 3번 문항
- **Q**. 정수(int)와 실수(float)를 함께 연산할 때, 파이썬이 데이터 손실을 막기 위해 정수를 자동으로 실수형으로 변환해주는 현상을 가리키는 용어로 가장 적절한 것은 무엇인가요?
- **A**. 업캐스팅(묵시적 형변환)
- *항상 연산은 같은 자료형만 가능하며, 파이썬은 정수와 실수를 연산할 때 표현 범위가 더 넓은 실수형 쪽으로 자동 변환하여 데이터 손실을 방지하는데, 이를 업캐스팅(묵시적 형변환)이라고 합니다. 명시적 형변환은 개발자가 int(), float() 등을 직접 호출하는 경우이며, ValueError는 변환 실패 시 발생하는 에러이므로 오답입니다.*
#### 4번 문항
- **Q**. 파이썬 f-string에서 변수명 뒤에 특정 기호를 붙이면 변수의 이름과 현재 값을 동시에 출력하여 디버깅에 활용할 수 있습니다. 이때 사용하는 기호(조절자)는 무엇인가요?
- **A**. \=
- *f-string 중괄호 안에서 변수명 뒤에 등호(=)를 붙이면 f"{score=}"처럼 변수 이름과 값이 함께 출력되어 별도 라벨 없이도 상태를 추적할 수 있습니다. 이는 로그 확인과 디버깅에 유용한 3세대 문자열 형식화 기능입니다.*
#### 5번 문항
- **Q**. 다음 코드의 실행 결과로 올바른 것은 무엇인가요? `result = 10 + 2 * 5 > 25` `print(result)`
- **A**. 20 **(오답)**
- *연산자 우선순위에 따라 곱셈(\*)이 먼저 계산되어 2 * 5 = 10이 되고, 이어서 10 + 10 = 20이 계산됩니다. 마지막으로 비교 연산 20 > 25는 False이므로 최종 결과는 False입니다. 산술 연산이 비교 연산보다 먼저 처리된다는 점을 이해해야 합니다.*
