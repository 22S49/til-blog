# 증가·감소 연산자
- ＋＋ ─ 1씩 증가
- －－ ─ 1씩 감소
```javascript
/* 후위 증가 연산자 */
let num1 = 10;
let num2 = num1++; // ① num1의 현재값(10)을 num2에 할당 ② num1 1 증가
console.log(num2, num1); // 10, 11

/* 전위 증가 연산자 */
let num1 = 10;
let num2 = ++num1; // ① num1 1 증가 ② num1의 현재값(11)을 num2에 할당
console.log(num2, num1) // 11, 11
```
# 일치 연산자
- 동등성 ─ 두 값이 논리적으로 같은 값인지 확인 ⇢ 타입이 다르면 강제 형변환 후 비교
	- == ─ 값이 같다. 
	- != ─ 값이 다르다.
	- `1 == "1"` ─ true
- 동일성 ─ 두 변수가 완전히 같은 논리 값 & 타입 & 객체를 참조하는지 확인
	- === ─ 원시값은 값과 타입이 같고 객체는 참조 대상이 같다.
	- !== ─ 원시값은 값 또는 타입이 다르고 객체는 참조 대상이 다르다. 
	- `1 === "1"` ─ false
- 부정 연산 ─ ! (참 ⇢ 거짓, 거짓 ⇢ 참)

| 구분         | Python                  | Javascript                           |
| ---------- | ----------------------- | ------------------------------------ |
| 값(내용) 비교   | `==`                    | `==` (형변환 O, 느슨) / `===` (형변환 X, 엄격) |
| 참조(정체성) 비교 | `is`                    | `===` (원시값 아닌 객체에 한해)                |
| 형변환 있는 비교  | 없음 (항상 엄격)              | `==`                                 |
| 특수 비교      | 없음                      | `Object.is()` (NaN, ±0 처리)           |
| 권장 실무 패턴   | 값은 `==`, None/싱글턴은 `is` | 항상 `===` 사용, `==`는 지양                |
## 동등성 비교 버그 케이스
```javascript
/* 예측 불가능한 형변환 */
console.log(0 == "");          // true
console.log(0 == "0");         // true
console.log("" == "0");        // false  <- 어? 방금 위 둘은 true였는데
console.log(0 == false);       // true
console.log(false == "false"); // false  <- 문자열 "false"는 false가 아님
console.log(null == undefined);// true
console.log(null == 0);        // false  <- null은 0과도 다름

/* 배열/객체가 숫자나 문자열로 둔갑*/
console.log([] == false);      // true  ([] -> "" -> 0)
console.log([] == "");         // true
console.log([0] == false);     // true  ([0] -> "0" -> 0)
console.log([1,2] == "1,2");   // true  (배열이 문자열로 변환됨)
console.log("" == []);         // true
```

> [!NOTE] 부동소수점 오차
> - 컴퓨터는 2진법, 사람은 10진법 사용하기 때문에 컴퓨터는 소수를 계산할 때 미세한 오차를 만든다.
> 	- *e.g.* 1/3을 소수점으로 표현할 때 2진법과 10진법 모두 무한소수 발생 (0.333…, 0.000110011…)
> - 부동소수점 오차를 살펴보기 위한 예시 코드
> 	- `console.log(0.1 + 0.2); // 0.30000000000000004` 
> 	- `console.log(0.1 + 0.2 === 0.3); // false`
> - 따라서 실수는 단순히 동등성 또는 동일성을 비교하기보다 허용 오차를 사용하는 것이 안전하다.
> 	- e.g. `Math.abs(a - b) < 0.001`
> 	- 최근에는 허용 오차의 표준값을 JS가 미리 정의해 둠 ─ `Number.EPSILON`(약 \(2.22 × 10^{-16}))

## 조건문
```javascript
if (조건식) { // 조건식: 참, 거짓을 판별하는 연산식 (비교·논리연산)
   (조건식이 참일 때 실행되는 구간);
} else if (조건식) {
   (조건식이 참일 때 실행되는 구간);
} else {
   (모든조건이 거짓일 때 실행 구간);
}
```
### 삼항 조건식
```javascript

```

### 단락회로평가
- OR 연산자 ─ 앞 쪽의 값이 falsy이면 뒤의 값으로 넘어간다.
```javascript
let num = 0;
num = num || 10;  // 앞 쪽의 값이 falsy 이면 다음 값으로 넘어가서 기본값 설정에 활용
console.log(num); // 10
```
- NULLISH ─ 앞 쪽의 값이 null 또는 undefined이면 뒤의 값으로 넘어간다.
```javascript
let num = 0;
num = num ?? 10;  // 앞 쪽의 값이 null 또는 undefined가 아니므로 그 값을 그대로 반환
console.log(num); // 0
```
- AND 연산자 ─ 앞 쪽 값이 참이면 뒤의 값을 출력한다. (간단한 조건문처럼 사용 가능)
```javascript
// 예1
const message = "";
message && console.log(message); // 거짓 ⇢ 실행 안됨
// 예2
const message = "안녕하세요.";
message && console.log(message); // 참 ⇢ "안녕하세요." 출력
```

> [!NOTE] 파이썬과 자바스크립트 간 참/거짓 취급 비교
> - 파이썬 ─ 0, "", None, [], {}, False -> falsy
> - 자바스크립트 ─ 0, "", null, undefined, NaN, false ⇢ falsy
### 선택문
- `switch ~ case:` 
	- 동일성 비교로 키워드가 매칭되면 코드 실행이 시작되고 코드의 끝 (또는 `break`) 을 만나면 실행 종료
	- 키워드가 매칭되는 케이스가 없으면 코드가 실행되지 않고 undefined 반환
	- 키워드가 매칭되는 케이스가 없으면 `default:` 케이스로 undefined가 아닌 원하는 반환을 지정할 수 있다. 
- `break;` ─ 실행 흐름을 중단
	- `break;`가 없어서 시작점부터 코드의 끝까지 실행되는 (다음 케이스로 이어지는) 것을 fall-through라고 한다. 
	- 선택문에서 `break;`는 조건 (매칭 여부) 을 판단하는 것이 아니라 예외 처리 성격에 가깝다. (fall-throught 방지)
```javascript
const rank = 2;
switch(rank) { // 매칭이 되면 실행되는 구간을 나눔
    case 1: console.log("금메달");
	    break;
    case 2: console.log("은메달"); // 매칭! 코드 실행의 시작점이 됩니다.
	    break;
    case 3: console.log("동메달"); 
	    break;
	default:
		console.log("등수는 1, 2, 3 중에서 입력하세요.")
}
```

> [!NOTE] 자바스크립트는 왜 조건문 외에 선택문이 있을까?
> - 케이스가 많아질 수록 상대적으로 가독성이 좋고 실행 속도(엔진 최적화)가 빠르다. 
> - 하나의 값이 여러 후보 값 중 어디에 해당하는지 비교하는 값 매칭에 특화된 문법
> 	- 반면에 조건문은 참/거짓을 판단하는 임의의 논리식으로서 논리 판단에 특화된 문법
> 		- 다시 말해 조건문은 복잡한 조건, 범위 비교, 여러 변수의 조합이 필요할 때 사용
> - C 계열 언어의 문법 스타일을 물려 받았기 때문에 선택문 채택 (C ⇢ Java ⇢ Javascript)
# 반복문
## for 문
- 횟수가 정해진 (순서가 있는) 반복에서 사용하는 문법
	- 초기화식 ─ 반복문 내부에서 사용될 초기값을 설정하는 식
	- 조건식 ─ 반복을 유지하는 조건식
	- 증감식 ─ 조건을 중단하기 위한 숫자 증가·감소식 (*cf.* 증감식이 없으면 무조건 true이기 때문에 무한 반복)
```javascript
for (초기화식; 조건식; 증감식) { 
	(조건식이 참일 때 실행 구간);
}

/* 반복을 10번 출력하는 반복문 */
for (let i = 0; i < 10; i++) {
    console.log("반복");
}

/* 여러개의 변수와 증감식 사용 */
for (let i = 0, j = 10; i < 10; i++, j--) { // 동일한 선언자인 경우 콤마로 변수 선언 연결 가능
    console.log("i=", i, "j=", j);
}
```
### 구구단 예제
```javascript
// 기본형
for (let i = 2; i < 10; i++) {
    console.log(`---${i}단---`)
    for (let j = 1; j < 10; j++) {
        console.log(`${i}×${j}=${i*j}`)
    }
}

// 단수보다 곱하는 수가 클 때만 출력 (기본형)
for (let i = 2; i < 10; i++) {
        for (let j = 1; j < 10; j++) {
            if (i < j) {
                console.log(`${i}×${j}=${i*j}`)
            }
    }        
}

// 단수보다 곱하는 수가 클 때만 출력 (부정 연산형)
for (let i = 2; i < 10; i++) {
        for (let j = 1; j < 10; j++) {
            if (!(i >= j)) {
                console.log(`${i}×${j}=${i*j}`)
            }
    }        
}

// 단수보다 곱하는 수가 클 때만 출력 (건너뛰기)
for (let i = 2; i < 10; i++) {
        for (let j = 1; j < 10; j++) {
            if (i >= j) {
                continue;
            }
            console.log(`${i}×${j}=${i*j}`)
    }        
}
```
## while 문
- 조건식이 거짓이면 실행을 중단한다.
```javascript
while (조건식) {
	  (조건식이 참일 때 반복되는 구간);
	  (반복을 중단시키는 코드); // break와 함께 쓰이는 코드
}

/* 예제 */
while(true) {
    const menu = prompt("메뉴선택");
    if (menu === "q") {
        console.log("중단합니다.")
        break;
    }
}
```
## do-while문
- 조건식이 거짓이더라도 한 번 실행을 보장한다. 실행을 먼저 하고 조건 확인 후 출력해야 하는 경우 많이 사용한다.
- 사용례
	- 메뉴 반복 출력 ─ 프로그램 시작 시 메뉴를 최소 한 번은 보여줘야 함
	- 사용자 입력값 검증 ─ 값을 일단 입력받아야 검사를 할 수 있는 경우 (*e.g.* 비밀번호 입력, 나이 입력 후 유효성 검사)
	- 재시도 로직 ─ 한 번은 시도해보고, 실패하면 조건에 따라 반복 (*e.g.* 서버 연결 시도, 파일 읽기 시도)
	- 게임 루프의 턴 진행 ─ 최소 한 턴은 진행하고 나서 종료 조건(게임 오버 등)을 확인
	- 데이터가 1개 이상 있다고 보장 순회 ─ 처음부터 조건 검사가 무의미한 경우 (리스트에 항상 헤더 노드가 있는 경우)
	- 파일/스트림 읽기 ─ 먼저 한 번 읽어보고 EOF 여부를 그 다음에 판단해야 할 때
	- 사용자 확인(컨펌) 루프 ─ "계속하시겠습니까?" 같은 질문을 최소 한 번은 물어봐야 하는 경우
	- 캘리브레이션/초기화 작업 ─ 장치나 시스템을 일단 한 번 시도한 뒤 상태를 보고 반복 여부 결정
```javascript
do {
	(조건식이 참일 때 반복되는 구간);
} while (조건식);

/* while문 */
let i = 101, total = 0;
while (i <= 100) {
    total += i;
    i++;
}                           // 위에서 아래로 코드를 읽으니까 조건을 확인하고 거짓이면 실행하지 않음
console.log("합계:", total) // 합계: 0

/* do-while문 */
let i = 101, total = 0;
do {
    total += i;
    i++;                    // 위에서 아래로 코드를 읽으니까 일단 실행하고 
} while (i <= 100);         // 조건을 확인하고 거짓이면 다음을 실행하지 않음
console.log("합계:", total) // 합계: 101
```
## 반복문 흐름 제어
- break ─ 반복 중단
- continue ─ 반복 건너뛰기


> [!NOTE] 자바스크립트 반복문 종합 정리
> |반복문|용도|꺼내는 것|
> |---|---|---|
> |`for (;;)`|횟수/조건 기반 반복 ⇢ 순서를 직접 제어|직접 제어 (인덱스 등)|
> |`for...in`|객체의 키 순회|키 (문자열), 배열의 인덱스|
> |`for...of`|이터러블의 값 순회|값 (일반 객체에 사용 불가)|
> |`while`|조건이 참인 동안 반복|직접 제어|
> |`forEach`|배열 등의 요소마다 콜백 실행|값, 인덱스, 배열 (콜백 방식)|
> - 어떤 때 뭘 써야 할까?
> 	- 인덱스/횟수를 직접 제어 → 기본 `for`
> 	- 객체의 키 → `for...in` (또는 `Object.keys/entries` + `for...of`)
> 	- 배열 값 순회 (기본 선택) → `for...of`
> 	- 중단(`break`)이나 `await`이 필요 → `for`, `for...of`
> 	- 간단한 배열 처리 → `forEach`

# 예외 처리
```javascript
try {
	(예외가 발생할 가능성이 있는 코드);
} catch (err); {
	(예외가 발생하면 유입되는 구간); // 대안적 처리 또는 err 객체
} finally {
	(예외 발생에 무관하게 무조건 실행되는 구간);
}
```
- `throw` ─ 예외를 강제로 발생시키는 키워드 (≒ python의 raise)
	- `throw new(..)` ─ 내장 에러(에러 객체 생성자, error의 하위 생성자 객체)를 던질 때 
	- `throw new Error(..)` 클래스(생성자 함수) ─ 객체(인스턴스)를 만들기 위해 `new`를 써서 직접 에러를 던질 때
		- `TypeError` ─ 값의 타입이 예상과 다를 때
		- `RangeError` ─ 값이 허용 범위를 벗어났을 때
		- `SyntaxError` ─ 문법 자체가 틀렸을 때
		- `ReferenceError` ─ 존재하지 않는 변수를 참조할 때
```javascript
throw "에러남";        // throw + 문자열 (new 필요 없음, 문자열은 그냥 값이니까)
throw 404;             // throw + 숫자
throw { msg: "에러" }; // throw + 객체 리터럴 (new 없이 직접 만든 객체)
throw new Error("에러남");     // throw + (new로 만든) Error 객체
throw new TypeError("에러남"); // throw + (new로 만든) TypeError 객체
```
```javascript
try {
    let str;
    const str2 = str.toUpperCase(); // throw new TypeError(..) 형태로 던져졌다.(실행 중단)
    console.log(str2, "대문자로 변경 완료")
} catch (err) {
	console.dir(err) // 객체를 트리 구조로 펼쳐서 내부 슬롯(message, stack, name 등) 확인 가능
    console.log(err); // TypeError: Cannot read properties of undefined (reading 'toUpperCase')
                      // 또는 console.error(err) 로 출력하면 붉은색 하이라이트로 출력
}
```
# js 객체 리터럴

- 딕셔너리 구조(`{키:값, …}`)로 객체 리터럴 할당 ⇢ 이때 중괄호 안에 있는 요소를 프로퍼티라고 한다.
	- 함수도 객체이기 때문에 키 값에 대한 밸류로 함수를 지정함으로써 프로퍼티를 구성할 수 있다. 
- 접근
	- 마침표 연산자 ─ 속성의 이름이 [[2026-09-21#^a3d961|변수 이름 규칙]]에 해당하는 속성만 접근 가능
	- 대괄호 연산자 ─ 변수명 규칙에 해당하지 않는 속성을 접근하는 경우
- 추가 ─ 새로운 속성명(키)으로 값(밸류) 대입
- 수정 ─ 이미 있는 속성명(키)으로 값(밸류) 대입
- 삭제 ─ delete 연산자와 `객체참조변수.키값` 형태를 결합해서 프로퍼티 삭제
```javascript
/* 객체 리터럴 할당 */
const person = {
    2026: "등록기준", // 숫자 속성명은 문자열로 변환하여 처리 ("2026"와 동일)
    name: "김철수",
    age: 30,
    'student-no': 100,
    study: function () {
        console.log("공부한다.") // 함수는 속성명을 생략할 수 있음 (이 때 person.fuction(); 가능)
    },
};

/* 객체 리터럴 요소 CRUD */
console.log(person); // { name: '김철수', age: 30, study: [Function: study] }
console.log(person.age, person.name); // 30 김철수
console.log(person['age'], person['name']); // 30 김철수 
person.study(); // 공부한다.
person['study'](); // 공부한다.
person.student-no; // error 발생
person["student-no"]; // 100
person.address = "주소" // 없던 address 속성이 추가된다. 동일한 방식으로 수정도 가능하다. 
delete person.address; // adress 속성을 삭제한다. 
```

> [!NOTE] 통상적 의미의 객체란?
> - 목적이 있고, 목적을 달성하기 위한 행위(함수)와 목적의 특성(속성)으로 정의된 독립적인 단위(실체)
> - 객체지향 ─ 객체들이 모여서 프로그램을 구성한다. 객체 간 상호작용을 통해 객체와 프로그램의 목적을 달성한다.

> [!NOTE] 자바스크립트에서 중괄호의 의미
> 1. 객체를 만들 때 (객체 리터럴)
> 2. 코드 실행 범위를 지정할 때 (코드 블록) ⇢ 객체 아님
> 3. 구조 분해 할당을 할 때 ⇢ 객체를 부술 때 (객체를 부수기 때문에 객체를 만드는 것이 아님)
