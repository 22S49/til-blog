# 브라우저가 페이지를 열 때 생성되는 객체
- `window` ─ 브라우저 탭 전체를 나타내는 최상위(전역) 객체
- `document` ─ `window`의 속성으로, 그 탭에 로드된 HTML 문서 → 원래는 `window.document`지만 축약 사용
- **페이지 로딩 시 객체 및 이벤트 발생 절차**
	1. 브라우저가 해당 페이지용 `window`와 빈 `document` 객체 생성
	2. HTML을 위에서부터 읽으면서(파싱) 태그마다 노드를 만들어 `document` 아래에 붙임 (트리 내용 채우기)
		- 이 때는 `document.readyState === loading`인 상태
	3. 파싱이 끝나면 `DOMContentLoaded` 이벤트 발생 → HTML 파싱 끝, DOM 트리가 완성되었다는 의미
		- 이 때는 `document.readyState === interactive`인 상태
			- HTML 파싱이 끝나고 DOM에 접근 가능
			- 아직 이미지, CSS 등 모든 리소스가 로드된 상태는 아님
	4. 모든 로드가 완료되고 `load` 이벤트 발생 → 페이지 로드가 완전히 끝났다는 의미
		- 이 때는 `document.readyState === complete` 인 상태
	5. 페이지를 새로고침하거나 다른 페이지로 이동하면 기존 `document`는 버려지고 새로운 `document` 생성

> [!NOTE] script 태그 위치
> - 기본 원칙 ─ body 맨 끝에 위치
> 	- HTML은 위에서 아래로 파싱되는데, `<script>`를 만나면 파싱이 멈추고 스크립트를 실행 
> 		- script 태그를 head 영역에 두면 스크립트가 끝날 때까지 화면 렌더링이 지연 발생
> 	- 스크립트가 DOM 요소를 조작한다면, 그 요소가 아직 만들어지지 않은 상태라 `null` 에러 발생
> - 예외 사항 ─ head에 두는 경우
> 	-  `defer` 속성을 붙인 경우 ─ *e.g.* `<script src="app.js" defer></script>`
> 		- 파싱과 병렬로 js 파일을 다운로드하고, HTML 파싱이 끝난 뒤 js 파일을 실행 (외부 파일에만 적용 가능)
> 		- 동작 방식
> 			- 브라우저가 HTML을 파싱하다가 `defer` 스크립트를 만나면 파싱 지속 + js 파일 백그라운드 다운로드
> 			- HTML 파싱이 끝나면 (= DOM이 완성되면) `DOMContentLoaded` 발생 직전에 스크립트 실행
> 	- `async` 속성을 붙인 경우
> 		- js 파일 다운로드가 끝나면 바로 실행
> 		- DOM에 의존하지 않는 독립 스크립트(분석 도구 등)에 사용
> 	- `DOMContentLoaded` 이벤트 안에서 DOM에 접근하는 경우
> 	
> |               | 다운로드 시점 | 실행 시점 |
| ------------- | ------------ | ------------------------------------------ |
| `<script>` | 파싱 중단하고 다운로드 | 다운로드 직후 (DOM이 아직 미완성)                      |
| `defer`       | 파싱과 동시에 다운로드 | HTML 파싱 완료 후 작성 순서대로 실행  |
| `async`       | 파싱과 동시에 다운로드 | 다운로드 끝나는 즉시 (파싱을 중단하고 실행, 순서 보장 X)  |


> [!NOTE] 스크립트의 동기적 실행
> 1. HTML 문서에 스크립트가 button 요소보다 앞에 있는 상황 → 스크립트는 button 요소를 찾지 못한다. 
> 2. `const buttonEl = document.getElementById("button");` 
> 	- `console.log("buttonEl", buttonEl);` → `null` 반환
> 3. 그럼 스크립트가 button 요소를 찾도록 하려면
> 	- 스크립트를 body 태그가 닫히기 직전에 위치
> 	- HTML 문서 내에서 스크립트 태그에 `defer` 설정
> 	- `addEventListener`로 이벤트를 발생시켜 스크립트 실행 (스크립트를 이벤트 객체로 감싼다.)
> 		- 다시 말해서 `DOMContentLoaded` 이벤트(DOM 로드 완료) 시점에 실행한다는 의미

## BOM과 DOM
- 브라우저가 열리면 생성되고 연결되는 객체, 메서드, 구조의 설계와 명세
- BOM (Browser Object Model) ─ 별도의 표준은 없으나 대부분 HTML 표준을 따름
	- 웹문서 밖의 브라우저 자체를 다루는 모델 ─ 호스트 객체, 즉 `window`의 하위 객체들을 일컫는다.
	- e.g. `location.href`, `history.back()`, `navigator.userAgent`, `alert()`, `confirm()`, …
- DOM (Document Object Model) ─ W3C 표준을 따름
	- 웹문서의 내용(HTML 요소)을 다루는 모델 ─ HTML 요소를 찾고, 바꾸고, 추가하고, 지우는 일을 한다. 
	- 호스트 객체, 즉 `window`의 하위 객체 중 `document` 객체는 BOM이 아닌 DOM 영역으로 나뉜다. 
	- *e.g.* `document.querySelector()`, `classList`, `addEventListener`
```
window
├─ document ── html ── head                                        ← DOM (문서 내용)
│                   └─ body ── div ── img   (DOM은 트리로 깊어짐)
├─ location                                                       ┐
├─ history                                                        │
├─ navigator                                                      ├─ BOM (브라우저 기능)
├─ screen                                                         │
└─ alert(), setTimeout(), localStorage, …                         ┘
```

## Document 객체
- HTML 태그를 분석하고 요소를 선택(`querySelector` 등)하는 API를 활용할 수 있다. 
- DOM 트리 ─ HTML 문서를 노드들의 계층 구조로 표현한 것
	- `document` 객체는 DOM 트리의 최상위(루트) 노드이고 트리를 탐색 및 조작하는 메서드를 가진다. 
- DOM 조회
	- 아이디(id) ─ `document.getElementById("아이디")` ⇢ `documnet` 객체에서만, 하나만 선택 가능
	- 클래스(class) ─ `documnet.getElementsByClassName("클래스")` ⇢ 일반 요소에서도, 여러 개 선택 가능
	- 태그(tag) ─ `document.getElementsByTagName("태그")` ⇢ 일반 요소에서도, 여러 개 선택 가능 
	- 네임(name) ─ `document.hetElementsByName("네임")` ⇢ `document` 객체에서만, 여러 개 선택 가능
	- 쿼리셀렉터
		- `document.querySelector("CSS선택자")` ⇢ 일반 요소에서도, 첫 번째 하나만 선택 가능
		- `document.querySelectorAll("CSS선택자")` ⇢ 일반 요소에서도, 여러 개 선택 가능
- 웹문서 전체 (html) ─ `window.document.head`, `window.document.body`, … 
- 양식(form) ─ 양식 하위 입력 태그는 이름으로 바로 접근 가능
```html
<!-- 회원가입 폼 구조 생성 -->
<form name="frmSignUp">
    <input type="text" name="userEmail" placeholder="이메일 주소">
    <input type="password" name="userPassword" placeholder="비밀번호">
</form>
```
```js
/* 폼 이름(frmSignUp)과 하위 input 이름(userEmail)으로 접근 */
const email = frmSignUp.userEmail.value;
const password = frmSignUp.userPassword.value;
```
```html
<!-- 쇼핑몰 검색창 폼 구조 생성 -->
<form name="frmMallSearch">
    <input type="text" name="keyword" placeholder="검색어를 입력하세요">
</form>
```
```js
// 조금 더 안전하게 배열 형태로 접근하는 방법
const searchForm = document.forms['frmMallSearch'];
const searchWord = searchForm.elements['keyword'].value;
```
```html
<!-- 게시팜 글쓰기 폼 구조 생성 -->
<form name="frmBoardWrite">
    <input type="text" name="title" placeholder="제목">
    <textarea name="content" placeholder="내용"></textarea>
</form>
```
```js
// CSS 선택자를 이용해 이름 기반으로 안전하게 조작
const writeForm = document.querySelector('form[name="frmBoardWrite"]');
const boardTitle = writeForm.elements['title'].value;
```
- 노드 기반 상대적 접근
	- `parentElement` ─ 부모 요소 선택
	- `children` ─ 자식 요소 선택
	- `firstElementChild` ─ 첫 번째 자식 요소 선택
	- `LastElementChild` ─ 마지막 자식 요소 선택
	- `nextElementSibling` ─ 다음 형제 요소 선택
	- `previouElmentSibling` ─ 이전 형제 요소 선택

| 메서드                      | 붙는 객체            | 반환 타입               | 못 찾았을 때      | live 여부 |
| ------------------------ | ---------------- | ------------------- | ------------ | ------- |
| `getElementById`         | `document`       | `Element` (단일)      | `null`       | -       |
| `querySelector`          | `document`, 일반요소 | `Element` (첫 번째 하나) | `null`       | -       |
| `querySelectorAll`       | `document`, 일반요소 | `NodeList`          | 빈 `NodeList` | 정적      |
| `getElementsByTagName`   | `document`, 일반요소 | `HTMLCollection`    | 빈 컬렉션        | 실시간     |
| `getElementsByClassName` | `document`, 일반요소 | `HTMLCollection`    | 빈 컬렉션        | 실시간     |
| `getElementsByName`      | `document`       | `NodeList`          | 빈 `NodeList` | 실시간     |

> [!NOTE] DOM 조회 시 반환 타입은 유사 배열이기 때문에 접근 방법이 다름
> ||`NodeList`|`HTMLCollection`|
|---|---|---|
|인덱스 접근 `[0]`|가능|가능|
|`length`|가능|가능|
|`forEach`|가능|불가|
|`map`, `filter` 등|불가|불기|
|`for...of` 순회|가능|가능|
|이름/id로 접근 `col.namedItem("x")`|불가|가능|
> 　 
> ※ DOM 조회 시 `map`, `filter`가 필요하면 `Array.from()`이나 `[...list]`로 변환 후 접근

# 요소의 추가 정보
- 속성(Attribute) 조회 ─ `document.getAttribute("속성명")`
- 속성 지정, 추가, 변경 ─ `document.setAttribute("속성명")`
- 속성 제거 ─ `document.remove("속성명")`
- 속성 존재 여부 확인 ─ `document.has("속성명")`
- *cf.* 많이 쓰는 속성은 바로 접근 가능 (id, type, src, href, target, action, style, …)
	- 단, 클래스(class)는 예약어이기 때문에 사용할 수 없다. 대신 클래스네임(classname)으로 접근 가능
## 데이터 속성
- 기능과 관련 없지만 단순히 정보를 제공하는 속성도 추가할 수 있다.
- 데이터를 참고하기 위한 목적인 데이터 속성의 경우 관례적으로 속셩명에 `data-` 접두어를 사용한다. 
	- 일반 속성은 기능과 관련될 수 있기 때문에 접두어를 붙여서 의도하지 않은 구현을 방지하기 위함
	- `document.dataset` 객체가 키-값 형태로 쉽게 관리할 수 있게 지원한다. 
```js
// <input type="text" id="input">
const el = document.getElementById("input");

/* 속성 조회 */
el.getAttribute("type"); // 'text'

/* 속성 수정, 추가, 변경 */
el.setAttribute("type", "range"); // undefined
el.setAttribute("class", "input-txt"); // undefined
el.setAttribute("data-price", 10000); // undefined ⇢ 단순 정보 제공용 속성
el;
// <input type="range" id="input" class="input-txt" price="10000">

/* 속성 직접 접근 */
el.type = "number"; // 'number'
el;
// <input type="number" id="input" class="input-txt" price="10000">

/* 데이터 속성 */
el.dataset; // DOMStringMap {price: '10000'} → data- 접두어는 생략하고 매핑
el.dataset.productCnt = 3; // 데이터 속성 추가
el.dataset; // DOMStringMap {"price": "20000", "productCnt": "3"}
el;
// <input type="text" id="input" data-price="20000" data-product-cnt="3">
```

# DOM 동작을 확인하면서 노드 제어 실습
- DOM API로 노드를 생성하고 트리에 삽입해서 화면을 동적으로 갱신한다. 
	1. 노드 생성 ─ document 객체가 제공하는 메서드를 사용해서 메모리 상에 새 노드를 만든다. 
	2. 노드 조립 ─ 자식 노드를 부모 노드에 붙인다. 여전히 메모리 안에서 조립만 한 상태
	3. 노드 탐색 ─ DOM 트리에 삽입하기 위해 최상위 부모(DOM 트리 중 붙일 위치)를 찾는다.
	4. DOM 트리에 삽입 (화면에 반영) ─ 이미 생성되어 있는 DOM 트리에 붙여야 신규 노드가 보인다.
```js
/* 1. li 요소를 새로 만든다. 아직 화면(DOM 트리)에는 붙지 않은 상태 */
const menu4 = document.createElement("li");
menu4; // <li></li> ← 내용이 비어 있는 li 요소가 만들어 진다.

/* 2. "메뉴4"라는 텍스트 노드를 만든다. (태그가 아닌 순수 글자 조각) */
const menu4Txt = document.createTextNode("메뉴4");
menu4Txt; // "메뉴4"

/* 3. 텍스트 노드를 li 요소의 자식으로 붙인다. */
menu4.appendChild(menu4Txt);
menu4; // <li>메뉴4</li> ← li 안에 텍스트가 들어간 것을 확인

/* 4. 클래스가 "menus"인 요소(ul)를 선택한다. (첫 번째 일치하는 요소 하나만 반환) */
const menus = document.querySelector(".menus");

/* 5. 만든 li(menu4)를 .menus 요소의 마지막 자식으로 붙인다. (DOM 트리에 삽입) */
menus.appendChild(menu4); // <li>…</li> ← 붙인 li 요소가 반환되고 화면에 나타남

/* 6. 새로운 노드 한방에 추가하기 */
document.querySelector(".menus").insertAdjacentHTML("beforeend", "<li>메뉴4</li>");
```
