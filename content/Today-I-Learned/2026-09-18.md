# CSS 미디어 쿼리
- 뷰포트 (Viewport) ─ 현재 보이는 화면에 대한 설정 
- `width=device-width` ─ 장비의 너비 기준 
	- `device-width` ─ 세로 모드일 때의 가로 너비
	- `device-height` ─ 가로 모드일 때의 가로 너비 
- `user-scalable` ─ yes or no ─ 사용자 직접 확대 축소 가능 여부 
- `minimum-scale=1, maximun-scale=1` ─ 사용자 직접 확대 축소 비율 
- `initial-scale` ─ 처음 화면 비율
