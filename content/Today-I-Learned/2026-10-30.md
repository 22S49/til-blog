1번 문항

FastAPI에서 파일 업로드를 처리할 때 file: bytes = File()과 file: UploadFile을 비교한 설명으로 가장 적절한 것은?

D. bytes 방식은 비동기 스트리밍 인터페이스를 기본으로 지원한다.

에이타니

오답이에요

UploadFile은 작은 파일은 메모리에 두지만 약 1MB를 넘으면 임시 디스크에 나누어 저장하여 서버 메모리를 안전하게 유지합니다. bytes 방식은 파일 전체를 메모리에 한꺼번에 올리므로 크기에 비례해 메모리 사용량이 늘어나고, 메타데이터 제공이나 비동기 스트리밍 인터페이스는 UploadFile의 장점입니다.

3번 문항

StreamingResponse와 BackgroundTasks를 적용했을 때 시스템 가용성 변화에 대한 설명으로 가장 적절하지 않은 것은?

D. StreamingResponse로 대용량 비디오를 전송할 때는 전체 파일을 모두 다운로드해야만 재생을 시작할 수 있어 TTFB가 악화된다.

청크

에이타니

정답이에요

청크(Chunk)는 대용량 데이터를 한 번에 전송하지 않고 예를 들어 1MB와 같은 일정 크기로 분할한 데이터 조각을 의미합니다. StreamingResponse는 이러한 청크 단위로 데이터를 나누어 비동기 제너레이터를 통해 전달함으로써 서버의 메모리 부담을 줄입니다.

5번 문항

SQLAlchemy의 비동기 드라이버(asyncpg)를 사용한 비동기식 데이터베이스 연결 구조에 대한 설명으로 가장 적절한 것은?

B. 데이터베이스 응답을 기다리는 동안에도 서버는 다른 사용자의 요청을 계속 처리할 수 있다.

에이타니

정답이에요

비동기 드라이버를 사용하면 데이터베이스 응답을 기다리는 동안에도 서버가 멈추지 않고 다른 사용자의 요청을 처리할 수 있어, 적은 자원으로도 많은 연결을 유지할 수 있습니다. 동기식 방식이 오히려 응답 대기 중 서버 전체가 블로킹되고 더 많은 스레드 자원을 필요로 하며, 비동기 방식은 예약 시스템이나 실시간 채팅처럼 사용자가 몰리는 서비스에 적합합니다.
