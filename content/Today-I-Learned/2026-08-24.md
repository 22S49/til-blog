#### 프롬프트 5대 요소 — RTCCF
- Rold (역할) / Task (과업) / Context (배경지식) / Constraints (제약조건) / Format (형식)
```
[role]
당신은 20년차 동남아 여행 전문가입니다. 
[task]
여름에 가족들과 함께 휴식을 취할 수 있는 3박 4일 필리핀 여행 일정을 작성해주세요.
[context]
- 여행인원: 4인 가족 (초등학생 1명, 유아 1명)
- 이동수단: 렌터카 이용
- 숙박시설: 최소 4성급 이상 호텔
- 참고사항: 초등학생과 유아가 할만한 액티비티 포함
[constraints]
- 가족여행이므로 가족이 함께 참여할 수 있는 장소로 선택할 것
- 지역은 필리핀 세부로 한정할 것
- 초등학생과 유아가 있으므로 이동시간이 길지 않은 동선으로 선택할 것
[format]
- 1일차~4일차 각 [오전/점심/오후/저녁]으로 타임라인을 markdown 형식의 표로 정리할 것
- 각 항목들에는 참고할 여행팁을 두 줄 이내로 포함시킬 것
```

> \### \[앱 아이디어\]: 개인 사용자를 위한 직관적인 할일 관리 칸반보드 서비스
#### Numpy
``` python
import numpy as np
np.array([…])
```
- 일반적으로 데이터 연산을 하게 되면 메모리 효율성이 떨어짐 ⇢ 빠른 연산을 위해 Numpy 사용 
	- C로 개발되었기 때문에 메모리로 직접 접근하고, 그렇기 때문에 메모리를 효율적으로 이용
	- 동일한 자료형이 붙어있는 구조(메모리상 연속된 구조)로 메모리를 효율적으로 이용
	- 요소의 데이터 크기가 모두 동일하기 때문에(비트 숫자로 위치 이동)메모리를 효율적으로 이용
		- 인덱스 계산을 하는 것이 아니라 실제 위치를 이동하기 때문에 빠르게 접근 가능
- 배열(Array) 
	- 구조적으로 리스트와 비슷(인덱스 연산 가능)하지만 같은 자료형으로만 구성된다는 점에서 차이
		- cf. 파이썬 리스트: 리스트 조차도 객체, 바깥 주소 참조 형식, 다양한 자료형을 요소로 포함
	- 1차원 배열 — 선형 구조 (벡터) `vector = np.array([10, 20, 30])`
	- 2차원 배열 — 행렬 구조 (면 구조, 매트릭스)
	```python
	matrix = np.array([
	    [10, 20, 30],
	    [40, 50, 60],
	    [70, 80, 90]
	])
	```
	- 3차원 이상 배열 — 텐서(Tensor)
- 다차원 배열에서의 배열 선택과 슬라이싱
	- matrix\[행, 열]
	- matrix\[0:2, 1:3] — 행은 0에서 1까지, 열은 1에서 2까지 (이상~미만)
	- matrix\[:, 0] — 모든 행의 0번째 열
	- matrix\[1:, :2] — 행은 1부터 전체, 열은 1 이하
- dtype() — 자료형 명시 (e.g. `np.int`, `np.float64`)
- arange(시작, 종료, 증감단위) — 시작 이상 종료 미만으로 숫자 생성 `np.arange(1, 13) # 1~12`
- 축(axis)
	- 2차원 배열에서 연산의 방향 설정
	- axis=0 — 행 간 연산 (열 내 연산)
	- axis=1 — 열 간 연산 (행 내 연산)
- Broadcasting 연산 — 동시에 빠르게 값을 변환, 배열 간 연산, 큰 배열을 기준으로 연산 적용
- 행렬전치 — obj.transpose() 또는 obj.T
- 행렬곱 — 배치 연산
##### 차원 변경
- reshape(행, 열)
	- 1차원 배열을 지정된 행열  구조로 차원 수 변경
	- -1 옵션을 주면 자동 차원 변경 (행만 알면 열도 알고, 열만 알아도 행을 알 수 있으니까)
	- 차원과 요소의 개수가 일치하지 않는 경우 ValueError 발생
```python
# 아래 차원 변경 결과는 모두 동일
mat_3x4 = arr.reshape(3, 4)
mat_3x4 = arr.reshape(3, -1)
mat_3x4 = arr.reshape(-1, 4)
```
- flatten() — 2차원 배열을 1차원으로 평탄화 
#### 데이터 크기
- 비트(bit) — 0과 1로 표현할 수 있는 하나의 단위
- 바이트(byte) — 1바이트 = 8비트 / 0과 1로 표현할 수 있는 공간이 8개 있다. 
	- (-2^7) ~ (2^7 -1) — 0을 제외한 -256 ~ 255 까지의 숫자 표현 가능
	- 맨 앞 칸은 부호 비트 (음수와 양수를 표현) 이기 때문에 2의 7승만큼 표현 가능

### 데일리 퀘스트
#### 1번 문항
- **Q**. 다음 중 1 이상 45 이하 범위에서 무작위 정수 하나를 반환하는 코드로 올바른 것은?
- **A**. random.randint(1, 45)
- *random.randint(a, b)는 a 이상 b 이하 범위의 정수 난수를 반환하는 함수입니다. random.random()은 인자를 받지 않고 0.0~1.0 미만의 실수를 반환하므로 정수 인자를 넣는 것은 잘못된 사용이며, random.sample()과 random.choice()는 시퀀스(리스트 등)를 첫 인자로 받아야 하므로 정수 하나만으로는 사용할 수 없습니다.*
#### 2번 문항
- **Q**. 여러 값을 하나의 변수에 튜플 형태로 묶어 담는 것을 '패킹'이라고 합니다. 반대로 하나의 자료구조에 담긴 값들을 여러 개의 변수에 순서대로 나누어 담는 동작을 무엇이라고 하나요?
- **A**. 언패킹
- *시퀀스 자료구조의 요소들을 각각 독립된 변수에 순서대로 대입하여 분해하는 기술을 언패킹이라고 하며, 이때 자료구조의 요소 개수와 변수의 개수가 일치해야 정상적으로 분해됩니다.*
#### 3번 문항
- **Q**. 리스트 numbers = \[0, 1, 2, 3, 4, 5]가 있을 때, print(numbers\[::2])의 실행 결과로 올바른 것은?
- **A**. \[1, 3, 5] **(오답)**
- *슬라이싱의 세 번째 자리는 증감폭(Step)을 의미하며, 2를 지정하면 처음부터 2칸 간격으로 요소를 추출하여 \[0, 2, 4]가 반환됩니다. \[1, 3, 5]는 홀수 인덱스만 뽑았을 때의 결과이고, 전체 리스트 그대로나 역순 정렬은 각각 슬라이싱을 생략하거나 step에 -1을 지정했을 때 나오는 결과입니다.*
#### 4번 문항
- **Q**. 부모 클래스로부터 물려받은 메서드를 자식 클래스의 요구사항에 맞게 새롭게 재정의하여, 호출 시 부모의 원본 메서드 대신 실행되도록 하는 객체지향 기법을 무엇이라 하나요?
- **A**. 메서드 오버라이딩 (메서드 재정의)
- *자식 클래스에서 부모와 동일한 이름의 메서드를 다시 구현하면, 자식 객체에서 해당 메서드를 호출할 때 부모의 원본 대신 재정의된 메서드가 최우선으로 실행됩니다. 이를 메서드 오버라이딩이라고 합니다.*
#### 5번 문항
- **Q**. 다음 중 프로그램 실행 도중에 발생하는 '런타임 예외(Exception)'에 해당하는 것은?
- **A**. 실행 중에 0으로 나누기 연산을 시도한 경우
- *콜론 누락, 들여쓰기 불일치, 괄호 미매칭은 모두 실행 전 단계에서 인터프리터가 걸러내는 구문 오류(Syntax Error)입니다. 반면 0으로 나누는 연산은 문법적으로는 문제가 없으나 실행 중에 ZeroDivisionError라는 런타임 예외를 발생시킵니다.*
