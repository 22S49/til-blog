### 연습장
#### 사이킷런(scikit-learn)
- 파이썬 머신러닝 라이브러리
- numpy 배열 기반으로 설계 — 독립변수는 항상 2차원이어야 하고, 종속변수는 1차원이어도 상관 없음
- DataFrame 데이터로 모델을 돌릴 때에는 `X.values.reshape(-1, 1)`  권장 (일관성, 호환성 측면)
	1. `X.values` = `to_numpy()`
		- 순수한 숫자 배열만 남기기 (X가 시리즈라면 1차원 배열, X가 데이터프레임이라면 2차원 배열)
	2. `X.values.reshape(-1, 1)
		- 배열이 1차원일 때 2차원으로 변환 (이미 2차원 배열인 경우 해도 되고 안 해도 됨)
		- (-1, 1) — 행 축의 크기는 알아서 계산하고 컬럼 수는 1개로 고정
		- e.g. `df['price'].values.reshape(-1, 1)` — 1차원 배열인 시리즈를 2차원으로 변환
		- cf. 배열의 차원 확인하기 — `X.shape` ⇢ 1차원이면 (n, ) 2차원이면 (n, 1) 출력
- 최근 사이킷런 버전에서는 DataFrame을 그대로 넣어도 대부분 작동한다. (알아서 변환)
	- e.g. `df[['price']].values`
			- 이미 2차원 DF이라면 .reshape 안 하고 .values만 해도 된다. 
			- 근데 최근 버전에서는 알아서 변환해 주므로 `df[['price']]` 그대로 사용해도 된다. 
#### 데이터 스케일링 (데이터 정규화)
- 독립변수 간 수치의 규모, 단위 등이 서로 달라 차이가 크면 오차 계산이 과해지기 때문에 오버슈팅 발생
- MinMaxScaler — 0 ~ 1 사이로 압축, 상대적인 크기를 비교하기는 어려울 수 있다. 
		$$X_{new} = \frac{X - \text{최솟값}}{\text{최댓값} - \text{최솟값}}$$
		
- StandardScaler — Z-Score 기준 압축, 평균을 0으로 표준편차를 1로 조정하고 상대 비교도 가능하다.
		$$X_{new} = \frac{X - \text{평균}}{\text{표준편차}}$$
#### 데이터 분할
- 과적합 방지 목적
	- 단, 데이터 분할 시 데이터가 편향되어 오히려 문제가 생길 수 있으므로 섞어줘야 한다. (shuffle=True)
- 데이터 분할 기준
	- 학습 세트(Train Set) — 모델이 학습하는 데이터
	- 검증 세트(Validation Set) — 학습 주기(Epoch or Batch)마다 모델을 평가하기 위한 데이터
	- 테스트 세트(Test Set) — 모델이 학습을 완료하고 최종적으로 모델 성능을 평가하기 위한 데이터
	- `test_size` 설정 시 유의점 — 2차에 걸쳐 데이터를 분할할 경우 2차 분할 시 1차 모수 규모 대비로 설정
		$$\text{테스트사이즈(2차)} = \frac{\text{원하는 검증세트 비율}}{1 - \text{테스트사이즈(1차)}}$$
- 데이터 분할 이후
	- 랜덤으로 데이터가 분리되었기 때문에 분리된 데이터의 인덱스는 정리해주는 것이 좋다. 
		- `x_train = x_train.reset_index(drop=True)` 
		- `x_valid = x_valid.reset_index(drop=True)`
		- `x_test = x_text.reset_index(drop=True)
#### 모델링 파이프라인
- `model.fit()`
	- 지정한 epoch 또는 batch 만큼 아래 주기를 반복한다.
		- 검증 과정 자동화 도구 — `GridSearchCV`나 `cross_val_score`
		- 학습 주기 최적화 도구 — tensorflow의 `Early Stopping`
	- **학습 과정** — 예측하고 가중치를 조정하는 일련의 과정 (예측값과 실제값 비교하는 건 학습이 아님)
		- ① 학습 세트로 예측한다. 학습 세트의 loss(손실)을 계산한다. (예측값과 실제값 비교)
		- ③ 검증후에 가중치가 손실에 얼마나 영향을 줬는지 기울기를 계산한다. (역전파)
		- ④ 옵티마이저가 기울기를 바탕으로 가중치를 업데이트한다. 
			- 가중치를 업데이트한다 = 보폭(학습률)만큼 이동한다. = 가중치 최적화 
			- 참고 — [[2026-08-26#^b648ed]]
		- ⑤ 새 가중치로 예측한다. 학습 세트의 loss(손실)을 계산한다.(예측값과 실제값 비교)
	- **검증 과정** — 규칙(모델)이 처음 보는 데이터에 얼마나 좋은 성능을 보이는지 확인하는 과정
		- ② 검증 세트로 예측한다. 검증 세트의 loss(손실)을 계산한다. (예측값과 실제값 비교)
		- ⑥ 새로운 규칙(모델)으로 예측한다. 검증 세트의 loss(손실)을 계산한다. 
	- 성능 확인
		- 검증 과정에서의 손실인 val_loss가 계속 낮아지면 학습이 잘 되고 있는 것
		- loss는 계속 낮아지는데 val_loss는 오히려 올라가기 시작하면 과적합이 시작됐다는 신호
			- 과대적합(Overfitting) : 학습을 해도 성능이 향상되지 않는다. 오히려 손실(Loss)이 커진다.
			- 과소적합(Underfitting): 학습이 덜 된 상태여서 정확도가 떨어지는 상태
			- 학습은 적절히 해야 좋다. 더 이상 로스가 떨어지지 않을 때 학습을 종료하는 게 최적
				- cf. 최적 학습 횟수에서 알아서 학습을 중단하는 Tensorflow EarlyStoping 기법
- `model.evaluate()`
	- **테스트 과정** 
		- 최종 규칙(모델)과 테스트 세트로 예측한다. 
		- 예측값과 실제값을 비교하고 최종 평가 지표를 반환한다.
		- 모델 유형별 평가 지표
			- 회귀 모델 — MSE, RMSE, MAE, R²
			- 분류 모델 — Accuracy, Precision, Recall, F1, Confusion Matrix
#### 학습-검증 과정 흐름
- 예측 ⇢ 손실 계산 ⇢ 역전파(기울기) ⇢ 옵티마이저(가중치 업데이트) ⇢ 예측 ⇢ … ⇢ 최적 가중치 발견
#### 학습-검증 용어 정리
- **가중치(Weight)** — 모델의 파라미터 (크기 정보 + 상태 정보), 손실함수의 독립변수
- **손실함수(Loss Function)** — 모델의 손실(Loss)를 구하는 식
	- 손실은 y와 y_hat의 차이이고 y는 x와 w로 계산된다. 즉, 손실 또한 x와 w로 계산된다.
	- 모델 학습 환경에서 데이터셋(x, y)은 상수이고 가중치(w)는 변수이다. 
	- 따라서 손실을 종속변수로 두는 손실함수는 가중치(w)를 독립변수로 갖는다. ⇢ 가중치의 함수
	- 손실함수 종류 — MSE, MAE, Cross-Entropy, Huber Loss 등
- **손실(Loss)** — 오차의 대표값, 예측값(`y_hat`)과 실제값(`y`)의 차이를 하나의 숫자로 요약한 것
- **규제(Regularization)** — 손실(Loss)을 계산할 때 가중치를 통제 (벌점 부여)
- **기울기(Gradient, `∂Loss/∂w`)** — 손실(Loss)을 가중치로 미분한 값 
	- 가중치(w)를 바꾸면 손실(Loss)이 얼마나 변하는지를 계산한 값 (변화율)
		- 미분 대상 — 손실 함수
		- 미분 변수 — 가중치
		- 계산 결과 — 기울기 
	- 현 가중치(w)를 어느방향으로 얼마나 바꿔야 하는지 알려주는 값 (크기 정보 + 방향 정보) 
		- 미분값이 양수이면 ⇢ 가중치를 늘릴 때 손실도 증가 ⇢ 그래서 가중치를 줄여야 한다. (결정)
		- 미분값이 음수이면 ⇢ 가중치를 늘릴 때 손실도 감소 ⇢ 그래서 가중치를 늘려야 한다. (결정)
		- *그럼 이제 적절한 가중치를 찾았다고 할 수 있는 근거는? 테스트 데이터의 정답 레이블*
		- 참고 — [[2026-08-26#^b0efc7]]
- **역전파(Backpropagation)** — 기울기를 연쇄법칙(chain rule)으로 거꾸로 전파시키는 것
	- 각 층의 가중치별 기울기를 계산하는 알고리즘, 기울기를 실제로 계산해내는 과정(방법)
- **옵티마이저(Optimizer)** — 기울기의 부호를 반대로 뒤집어서 가중치 업데이트하는 역할
	- 기울기가 손실이 증가하는 방향을 가리키니까, 그 반대로 가중치를 이동시켜야 손실이 줄어든다.
	- 옵티마이저가 가중치를 조정하기까지 손실이 점점 낮은 지점으로 수렴해 가는 것이 학습(Train)

#### 다중회귀모델
- 독립변수가 여러 개인 회귀 모델
- 독립변수가 너무 많으면 손실(Loss)이 높아질 수 있다. — 예측의 정확도가 떨어진다. 
	- 독립변수가 늘어날 수록 모델의 차원과 자유도가 높아져 사소한 노이즈도 학습 ⇢ 과적합
	- 독립변수 간 상관관계가 강할수록 분산이 과도하게 커져 모델이 불안정해 짐 ⇢ 과적합
- 다중회귀모델이서 과적합을 방지하기 위한 방법
	- 규제(Regularization)
		- 가중치만 통제하는 기법이다. (편향에는 적용하지 않는다.)
			- 편향은 스케일에 따른 과적합에 영향을 미치지 않기 때문에 통제 대상이 아님
		- 손실이 튀어서 예측 정확도가 떨어지지 않도록 손실을 계산하는 단계에서 규제가 끼어든다. 
			- 규제항(벌점) — 가중치를 0으로 당기는 힘, 모든 가중치에 동일한 규칙으로 작용한다.
				- 중요한 특성 — 가중치가 커야 하는데 규제항이 0으로 당기니까 손실이 반발함
					- 중요한 특성의 가중치가 0이 되면 손실이 커지니까 `규제 < 손실`이 되어서 지지
				- 가벼운 특성 — 가중치가 작아도 되니까 규제항이 0으로 당겨도 손실이 내버려 둠
					- 가벼운 특성은 노이즈이거나 영향력이 작은 독립변수 ⇢ 손실이랄게 없다!
					- 가벼운 특성의 가중치가 0이 되어도 손실은 어짜피 0이니까 `규제 = 손실` 균형
					- 가벼운 특성의 손실이 0이라는 건 예측을 잘 한다는 게 아니라 영향력이 낮다는 의미이므로 규제항이 가중치를 0으로 당기게 두어야 전체 모델의 정확도가 높아진다.
			- 총 손실 = 손실(Loss) + λ × 규제항 ⇠ 총 손실이 실제 미분(역전파) 대상
		- 규제 강도(λ)
			- 규제항이 총 손실에서 얼마나 큰 비중을 차지할지 조절하는 하이퍼 파라미터
			- 너무 크면 규제가 손실(Loss)을 압도해서 예측 자체를 못 하게 되고 (과소적합) 
			- 너무 작으면 규제 효과가 없어서 과적합 억제가 안 된다. ⇢ 적절한 제어 필요
		- L2 규제 (Ridge) — MSE + 모든 독립변수들의 가중치를 제곱하여 더한 값 × 규제 강도
			- 가중치와 규제항의 크기가 단조 증가관계이고 규제항은 손실을 견제하는 역할을 한다. 
		- L1 규제 (Lasso) — MSE + 모든 독립변수들의 가중치의 절대값을 더한 값 × 규제 강도
			- 영향력이 작은 특성의 가중치를 0으로 만들어서 아예 탈락시켜 버리는 효과가 있다. 
	- 차원 축소 — PCA 등을 통해 중요한 독립변수만 남기기
	- 변수 선택 — AIC, BIC 등의 기준을 사용해 유의미한 독립변수만 남기기
- 특성 공학 — 어떻게 하면 전처리를 잘 할 수 있을까? 를 고민하고 엔지니어링 하는 분야
	- 특성이 강하다. = 영향력이 크다. = y의 변화를 크게 한다. = 가중치가 크다.
	- 특성이 약하다. = 영향력이 작다. = y의 변화가 크지 않다. = 가중치가 작다. 
	- e.g. 결측치 처리, 이상치 제거, 스케일링, 요약변수 생성, 파생변수 생성 등
		- 파생변수 생성 — 특성들을 조합해서 새로운 특성을 추가해주는 전처리 기법
			- 단, 너무 특성을 많이 생성하면 과적합될 수 있다. 적절하게 활용해야 한다.

#### 1번 문항
- **Q**. 머신러닝에서 데이터를 Train, Valid, Test 세트로 나누어 학습시키는 가장 큰 이유는 무엇인가요?
- **A**. 모델이 정답을 통째로 외우는 과적합을 방지하고 진짜 일반화 성능을 검증하기 위해서
- *훈련 데이터만으로 학습과 평가를 모두 하면 모델이 답을 외워버리는 과적합이 발생하므로, 한 번도 보지 않은 데이터로 최종 성능을 검증하기 위해 데이터를 분리합니다.*
#### 2번 문항
- **Q**. 집값처럼 원본 숫자가 너무 커서 인공지능 학습 시 보폭이 꼬여 최적점을 훌쩍 지나쳐버리는 현상을 무엇이라고 하나요?
- **A**. 오버슈팅
- *오버슈팅은 보폭(학습률) 다이얼이 너무 크거나 데이터 스케일이 커서 계곡 바닥을 지나쳐 반대쪽으로 튕겨 나가는 현상입니다. 이를 방지하기 위해 MinMaxScaler나 StandardScaler로 데이터를 스케일링합니다.*
#### 3번 문항
- **Q**. train_test_split 함수에서 random_state=42로 값을 고정하는 이유로 가장 적절한 것은 무엇인가요?
- **A**. 동일한 난수 시드를 사용해 실행할 때마다 동일하게 분할된 데이터를 재현하기 위해서
- *random_state는 데이터를 섞을 때 사용하는 난수표 번호로, 이를 고정하면 동료의 컴퓨터에서도 동일하게 쪼개진 데이터를 얻을 수 있어 재현성이 확보됩니다. 클래스 비율을 맞추는 것은 stratify 옵션의 역할입니다.*
#### 4번 문항
- **Q**. 릿지(Ridge) 회귀와 라쏘(Lasso) 회귀의 차이점을 가장 정확하게 설명한 것은 무엇인가요?
- **A**. 릿지는 가중치를 완만하게 축소하되 완전히 0으로 만들지 않고, 라쏘는 불필요한 변수의 가중치를 정확히 0으로 만든다
- *릿지는 L2 규제(제곱합)로 가중치를 0에 가깝게만 만들어 변수를 모두 보전하지만, 라쏘는 L1 규제(절대값합)의 뾰족한 경계 특성 때문에 불필요한 변수의 가중치를 정확히 0으로 만들어 변수 선택 효과를 냅니다. 두 방식 모두 편향(b)은 규제 대상에서 제외됩니다.*
#### 5번 문항
- **Q**. 독립 변수들끼리 지나치게 밀접한 상관관계를 가져 각 변수의 독립적인 기여도를 파악하기 어렵게 만드는 현상을 무엇이라고 하나요?
- **A**. 다중공선성
- *다중공선성은 변수 간 정보 중복으로 가중치 계수가 불안정해지고 모델의 해석력과 신뢰도가 떨어지는 현상입니다. VIF 수치가 10 이상이면 심각한 다중공선성으로 진단하여 변수 제거, 통합, 규제 모델 적용 등의 대응이 필요합니다.*
