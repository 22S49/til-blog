### 연습장
#### 변수의 유효 범위
- 변수 스코프 — 변수를 접근할 수 있는 범위
- 전역변수(global) — 함수 외부에 정의된 변수, 코드 전역에서 접근 가능
- 지역변수(local) — 함수 내부에 정의된 변수, 함수가 실행될 때만 유효
```python
# 1-1
a = 10 # 전역변수
def func():
    b = 20    # 지역변수
print(a, b) # NameError - func()를 호출하지 않았으므로 print(b) 불가

# 1-2
a = 10
def func():
    b = 20
    print(f'{a=}, {b=}') # 함수 내에서는 전역변수 호출 가능
func() # a=10, b=20

# 2-1
def outer():
    a = 10
    print('b:', b)
    def inner():
        b = 20
outer() # NameError
# outer() 입장에서는 b가 존재하지 않음, inner()가 호출되어야 존재하기 때문

# 2-2
c = 30
def outer():
    a = 10
    print('c:', c)
    def inner():
        b = 20
        print(f'{a=}, {b=}, {c=}')
    inner() # outer() 함수 내에서 inner() 함수 호출
outer() # inner() 호출했으므로 NameError 없이 실행 가능, c는 전역번수 호출 제약 없음
```
#### LEGB 스코프
- Local — 지역변수
- Enclosing — 외부함수변수
- Global — 전역변수
- Built_in — 내장변수
- 좁은 범위가 우선순위가 높다. (안쪽부터 바깥쪽으로 찾는 탐색 규칙)
	- L > E > G > B
```python
# 1
a = 'global'
def outer():
    a = 'enclosing'
    print('outer:', a) # outer: enclosing
    def inner():
        a = 'local'
        print('inner:', a) # inner: local
    inner()
outer()

# 2
a = 'global'
def outer():
    a = 'enclosing'
    print('outer:', a) # outer: enclosing
    def inner():
        print('inner:', a) # inner: enclosing
    inner()
outer()
```
#### global 키워드
- 남발하면 전역변수가 오염될 수 있으니 되도록 지양하되, 필요할 때만 써야 함
```python
# 1
a = 'global'
def outer():
    a = 'enclosing'
    print('outer:', a) # outer: enclosing
    def inner():
        global a # a라는 변수는 전역변수를 찾겠다.
        print('inner:', a) # inner: global
    inner()
outer()

# 2
a = True
def outer():
    a = 'enclosing'
    print('outer:', a) # outer: enclosing
    def inner():
        global a  # a라는 변수는 전역변수를 찾아서,
        a = not a # (비록 함수 내이지만) a전역변수를 수정하겠다.
        print('inner:', a) # inner: False
    inner()
outer()
```

	- 함수와 변수를 차별하지 않는다.

- 함수의 반환값으로 함수를 사용할 때 — 팩토리 함수, 클로저(Closure, 속박)
	- 값을 고정 후 새로운 함수를 만드는 역할
		- 함수의 반환값은 콜 스택에 쌓이기 때문에 호출 후에 삭제되어야 하는데 함수의 반환값을 다른 함수에 다시 사용할 수 있는 예외적인 상황, A함수의 지역변수를 다른 함수에서 여전히 참조하므로 이 경우에는 콜스택이 아닌 힙에 저장하고 클로저 환경을 조성
	- 클로저 — 내부 함수가 외부 함수의 변수를 기억하고 외부 함수가 끝난 뒤에도 그 변수에 계속접근할 수 있는 성질과 그 함수 자체를 지칭하는 말로 데이터 은닉, 상태 유지, 정보 보호에 활용
```python
def outer(num1): # outer()의 지역변수: num1, inner()
    def inner(num2):
        return num1 + num2
    return inner # 함수를 반환값으로 사용  

a # <function __main__.outer.<locals>.inner(num2)>
a = outer(10) # 항상 10을 더해주는 새로운 함수
# num1 값이 10으로 고정되어 있는 새로운 함수가 만들어 진 것
# 원래는 a = outer(10) 로 호출이 끝나고 메모리가 삭제되어야 하는데(콜스택)
# outer() 함수의 지역변수를 다른 함수에서 여전히 참조하므로 힙에 저장(예외)

a(20)  # 10 + 20
```

#### 콜백 함수
- 사용자 정의 함수
- 함수를 지금 당장 명세하진 않았는데, 나중에 함수를 정의하면 그 함수에 따라 작동하라는 의미 
- 콜백 함수를 키워드 인자로 받는 경우
```python
def change_numbers(*args, callback):
    numbers = list(args) # 튜플을 수정 가능한 리스트로 변경
    for i in range(len(numbers)): # 리스트의 요소만큼 반복
        numbers[i] = callback(numbers[i]) # 임의의 함수에 따라 리스트 요소 값 변경
    return numbers

def square(num): # 콜백으로 사용할 함수
    return num ** 2
    
change_numbers(10, 20, 30, callback=square) # [100, 400, 900]
# 콜백 키워드 지정 없이 쓰면 TypeError 발생하므로 유의
```
- 콜백 함수를 위치 인자로 받는 경우
	- 가변 인자와 함께 쓰기 때문에 callback을 맨 앞(위치 인자로 인식) 또는 맨 뒤(키워드 인자로 인식)로 위치해야 하며, 가변 인자와 쓰지 않을 때에는 callback는 위치 인자로 받게 되므로 순차열에 상관 없이 나열할 수 있음 
```python
# 1
def change_numbers(callback, *args):
    numbers = list(args) # 튜플을 수정 가능한 리스트로 변경
    for i in range(len(numbers)): # 리스트의 요소만큼 반복
        numbers[i] = callback(numbers[i]) # 임의의 함수에 따라 리스트 요소 값 변경
    return numbers

def square(num): # 콜백으로 사용할 함수
    return num ** 2
    
change_numbers(square, 10, 20, 30) # [100, 400, 900]

# 2
def calculate(a, b, callback):
    return callback(a, b) 
# 덧셈을 수행하는 콜백을 람다로 전달
result = calculate(5, 3, lambda x, y: x + y)
print(result)  # 출력: 8
```
#### 람다 함수
- 간단하게 일회용으로 사용하는 경우 한 줄의 식으로 간단하게 함수 정의
- 일회용으로 사용되므로 매개변수 이름도 최대한 간결하게 표현 (일반적으로 x )
```python
# 구조
lambda 매개변수, 매개변수, … : 처리 부분

# 예시 — 콜백 활용
def change_numbers(callback, *args):
    numbers = list(args)
    for i in range(len(numbers)):
        numbers[i] = callback(numbers[i])
    return numbers

change_numbers(lambda x: x ** 3, 10, 20, 30) # [1000, 8000, 27000]
```

```python
fruits = ['사과', '오렌지', '망고']
list(map(lambda x : f'**{x}**', fruits))

# map() 함수 예시와 동일한 결과를 내는 여러 방법들

fruits = ['사과', '오렌지', '망고']
```

- filter() — 특정 조건에서 데이터 선별, 최근에는 리스트 컴프리헨션을 더 많이 쓰는 추세
```python
# 1에서 10까지 숫자로 리스트 형성
numbers = [*range(1, 11)] # 1에서 10까지 범위를 *로 펼쳐주는 역할
list(filter(lambda x: x%2 == 1, numbers)) # [1, 3, 5, 7, 9]
```
#### 클로저(Closure)
- 고차함수(Higher Order Function)
- 클로저를 많이 쓰면 메모리 사용량이 많아지기 때문에 유의
- 예시
```python
# 1
def outer():
    num1 = 10
    def inner():
        num2 = 20
        print(num1 + num2)
    return inner
inner = outer() # num1은 inner에 의해서 사용되므로 힙 영역에 생성
inner() # 30

# 2
def add(num1):
    def _add(num2):
        def __add(num3):
            return num1 + num2 + num3
        return __add
    return _add
    
add(10)(20)(30) # 60

add10 = add(10) # add(10)을 고정하고 다른 함수의 인수를 받음
add10(30)(40) # 80

add10_20 = add(10)(20) # add(10), _add(20)을 고정하고 다른 함수의 인수를 받음
add10_20(30) # 60
```
#### 데코레이터
- 디자인 패턴 중 한 가지 — 코드를 작성할 때 문제를 해결하는 형식
#### 데코레이터 — 실행 성능 수치 측정
```python
# 1-1
def factorial_1(num):
    result = 1
    for i in range(1, num+1):
        result *= i
    return result

# 1-2
start = time.time() # 공통기능 → 써도 되고 안 써도 됨
result = factorial_1(10) # 콜스택이  1번 쌓인다 → 성능 우위, 핵심기능
print(result) # 3628800
end = time.time() # 공통기능
print('걸린 시간:', end-start) # 걸린 시간: 0.00019407272338867188

# 2-1
def factorial_2(num):
    if num < 1:
        return 1
    return num * factorial_2(num-1) # 재귀함수    

# 2-2
start = time.time() # 공통기능
result = factorial_2(10) # 콜스택이 10번 쌓인다, 핵심기능
print(result) # 3628800
end = time.time() # 공통기능
print('걸린 시간:', end-start) # 걸린 시간: 3.62396240234375e-05

# 3 — 개념 종합
def time_checker(callback, num):
    start = time.time()    # 공통기능
    result = callback(num) # 핵심기능 (e.g. 팩토리얼 연산 함수)
    end = time.time()      # 공통기능
    print('걸린 시간:', end-start)
    return result
time_checker(factorial_2, 10) # 걸린 시간: 1.1920928955078125e-06 3628800

# 4-1 — 데코레이터 구현
def time_check2(callback):
    def wrapper(*args, **kwargs):
        start = time.time()      # 공통기능
        result = callback(*args, **kwargs) # 핵심기능
        end = time.time()        # 공통기능
        print('걸린 시간:', end-start)
        return result
    return wrapper
    
# 4-2 — 데코레이터 선언
@time_check2
def add(num1, num2):
    return num1 + num2
add(10, 20)
```
#### 재귀함수 (Recursive)
- 같은 함수 내에서 같은 함수를 반복해서 호출하는 방법
- 구조가 단순해지기 때문에 코드의 구조가 단순해 진다.
#### 별표의 쓰임
```python
a = [10, 20]
def minus(num1, num2):
    return num1 - num2
minus(*a) # minus(a[0], a[1])
```

### 데일리 퀘스트
#### 1번 문항
- **Q**. LEGB 스코프 구조에서 변수 검색 우선순위가 가장 높은 영역과 가장 낮은 영역을 올바르게 짝지은 것은 무엇인가요?
- **A**. 지역 스코프(Local) — 내장 스코프(Built-in)
- *파이썬은 변수명을 찾을 때 가장 가까운 현재 함수 내부인 L(Local)을 1순위로 식별하고, 가장 마지막 단계로 파이썬이 기본 탑재한 B(Built-in) 영역을 비교합니다.*
#### 2번 문항
- **Q**. 다음 코드가 실행될 때 최종 print(counter)의 출력 결과는 무엇인가요? 
```python
counter = 0 

def increase(): 
	global counter counter += 1 
	
def local_increase(): 
	counter = 100 

increase() 
increase() 
local_increase() 
print(counter)
```
- **A**. 2
- *increase() 함수는 global 키워드로 전역 변수 counter를 직접 수정하므로 두 번 호출되어 값이 2가 됩니다. local_increase()는 같은 이름의 독립적인 지역 변수 100을 생성했다가 함수 종료 시 소멸시킬 뿐 전역 변수에는 영향을 주지 않습니다.*
#### 3번 문항
- **Q**. def 키워드 없이 lambda 매개변수: 표현식 형태로 작성하며, 이름이 없는 한 줄짜리 함수를 무엇이라고 부르나요?
- **A**. 람다함수
- *lambda는 이름이 없다는 뜻을 가진 익명 함수로, def 없이 한 줄의 표현식만으로 값을 반환하는 도구입니다.*
#### 4번 문항
- **Q**. numbers = \[1, 2, 3, 4, 5]에 대해 다음 코드를 실행했을 때 result의 값은 무엇인가요? 
  `result = list(filter(lambda x: x % 2 == 0, map(lambda x: x + 1, numbers)))`
- **A**. \[2, 4, 6]
- *map()이 각 요소에 1을 더해 \[2,3,4,5,6]을 만들고, filter()가 그중 짝수만 골라 \[2,4,6]을 반환합니다.*
#### 5번 문항
- **Q**. 클로저(Closure)의 동작 방식에 대한 설명으로 가장 적절한 것은 무엇인가요?
- **A**. 외부 함수의 실행이 완전히 종료된 후에도 내부 함수가 외부 함수의 변수 값을 기억하고 유지하는 구조이다
- *클로저는 외부 함수 종료 후에도 내부 함수가 외부 함수의 환경(변수)을 캡슐화하여 계속 기억하는 구조입니다.*
