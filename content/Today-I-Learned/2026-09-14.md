# 웹 문서
- HTML ─ 뼈대
	- HyperText Markup Language ─ 링크(페이지) 이동이 가능하고 태그(요소)로 구성된 언어
		- non-void element ─ `<태그이름> … </태그이름>` ─ 여는 태그와 닫는 태그로 구성
		- void element ─ `<태그이름>` ─ 출력을 담당하지 않는 단일 태그 
			- *e.g.* area, base, br col, embed, hr, img, input, link, meta, param, source, track, wbr, …
	- 문서의 구조와 내용을 정의하고 그 자체로는 정적
	- 확장자 ─ .html 또는 .htm
- CSS ─ 스타일
	- Cascading Style Sheet ─ 상위 요소의 스타일이 하위 요소에 전달되는 형식
	- 확장자 ─ .css
- Javascript ─ 동적 요소 등 
	- 사용자 동작에 반응하고 페이지를 동적으로 바꿔서 상호작용을 가능하게 지원
	- 확장자 ─ .js
# 웹 표준
- Web Standard
- 어떤 브라우저를 사용해도 동일한 화면, 동일한 기능이 동작해야 한다.
- 웹 문서의 기본 구성을 지켜야 한다. 
- 일반 문서와 관련성이 높은 태그들로 구성된다. 
```html
<!DOCTYPE html> <!--버전 태그-->
<html>          <!--문서 시작-->
	<head> .. </head> <!--title, meta 등 문서 정보 및 CSS, JS 등 문서 자원 정의-->
	<body> .. </body> <!--문서 출력 영역, 실제로 보이는 영역-->
</html>         <!--문서 종료-->
```
# HTML
## 태그 구성
  - 문단 태그 (Block property)
	  - 줄 개행이 있으면 문단 태그로 인식
		- 너비와 높이를 패딩할 수 있다. ⇢ 공간을 가진다. 
	- 문단 태그 안에 본문 태그를 쓸 수 있다. 
	  - p, div, h1, form, …
  - 본문 태그 (Inline property) 
	  - 줄 개행이 없으면 본문 태그로 인식
	  - 너비와 높이를 결정할 수 없다. ⇢ 공간을 가지지 않는다. 
	  - 본문 태그 안에 문단 태그를 쓸 수 없다.
	  - i, b, strong, u, a, span, …
  - 태그 속성 (attribute) ─ 태그 안에 작성하는 태그의 기능을 수행하기 위한 정보
	  - 일반 속성 ─ 속성의 값이 의미를 가짐
	  - 불리언 속성 ─ 이 속성이 태그 안에 존재하면 참(true), 없으면 거짓(false)
		  - *e.g.* `multiple="false"`처럼 불리언 값을 줘도 그 값을 반영하지 않는다. 속성 자체가 있기 때문에 True 상태

| 불리언 속성      | 용도                              |
| ----------- | ------------------------------- |
| `checked`   | 체크박스/라디오 기본 선택                  |
| `disabled`  | 입력 불가능하게 비활성화 (데이터 전송 X)        |
| `required`  | 필수 입력값                          |
| `readonly`  | 읽기 전용 (값은 보이는데 수정 불가, 데이터 전송 O) |
| `selected`  | select의 option 기본 선택            |
| `multiple`  | 파일/select에서 여러 개 선택 허용          |
| `autofocus` | 페이지 로드시 자동으로 포커스                |
## 서식 태그

| 외형 / 용도   | 시멘틱 태그 (의미 포함)          | 단순 스타일 / Presentational 태그 |
| :-------- | :---------------------- | :------------------------- |
| **굵게**    | `<strong>` (중요성/경고)     | `<b>` (시각적 부각)             |
| **기울임**   | `<em>` (말투의 강조)         | `<i>` (외래어/전문용어/관용구)       |
| **취소선**   | `<del>` (수정/삭제된 내용·이력)  | `<s>` (더 이상 유효하지 않은 정보)    |
| **밑줄**    | `<ins>` (새로 추가된 내용)     | `<u>` (맞춤법 오류/고유명사 등)      |
| **하이라이트** | `<mark>` (검색어 매칭/참조)    | CSS `background-color`     |
| **작은 글씨** | `<small>` (법적 고지/면책 조항) | CSS `font-size`            |

> [!NOTE] 시멘틱 태그와 비시멘틱 태그
> - 시멘틱 태그 ─ 태그 자체로 의미가 있는 경우
> 	- ① 검색엔진 최적화 ② 웹 접근성 확보 ③ 코드 가독성 향상 측면에서 유리하게 작용
> 	- *e.g.* form, table, video, …
> 	- cf. 레이아웃 태그 ─ 시멘틱 태그의 일종으로 웹 페이지의 구조를 형성한다. (div 대신 사용)
> 		- header, main, nav, section, article, aside, footer
> - 비시멘틱 태그 ─ 태그 자체로는 의미가 없는 경우 
> 	- *e.g.* br, hr, div, span, …

### 개행 태그
- \<p> `non-void element`
	- 문단(텍스트 덩어리)을 위한 태그, 문단(텍스트 덩어리)을 선언하는 태그
	- inline property를 포함할 수 있지만 다른 block property는 포함할 수 없다. 
- \<div> `non-void element`
	- block 단위로 줄바꿈이 필요할 때 ⇢ 줄 바꿈이 목적이라기보다 하나의 구역을 지정하고 싶을 때
	- div 단위로 CSS 스타일 설정을 할 수 있다. ⇢ 의미 없이 그냥 단락을 묶고 싶을 때에도 사용 가능
		- 텍스트, 다른 div, form, list, img 등 모든 inline property와 block property를 포함할 수 있다. 
		- 레이아웃 구성의 기본 단위
		- *cf.* \<span> ─ inline 단위로 \<div>와 같은 형식(스타일 지정 또는 JS 조작이 가능한 형식)이 필요할 때 
- \<br> ─ inline 단위로 줄바꿈이 필요할 때 `void element'
	- 한 덩어리 텍스트 안에서 줄만 바꾸고 싶을 때 사용 (*e.g.* 가독성 때문에 줄만 나누는 경우)
	- 태그에 의미가 없고, 화면 크기가 바뀌면 레이아웃이 깨지고, 유지보수가 힘들어지기 때문에  남발하지 말아야 한다. 
	- 정말 필요한 경우가 아니라면 되도록 CSS로 여백을 주고 \<br> 사용은 지양하는 것이 좋음
## 외부 연결
- \<a> ─ 하이퍼링크 태그
- \<iframe> ─ 임베디드 프레임 문서 (하위 브라우징 맥락)
- \<img> ─ 이미지 출력 태그
	- href 또는 scr ─ 이동할 경로
		- 절대 경로 ─ 전체 URL 또는 전체 파일 경로 ⇢ 경로 변경 시 출력 불가
		- 상대 경로 ─ 현재 경로(./) 또는 상위 경로(../)
	- name ─ 위치에 대한 별칭
	- target ─ 이동할 경로를 출력할 위치 (\_self(기본값), \_blank, \_parent, \_top)

| 속성                                 | 목적                   | 주로 사용되는 태그                      | 웹페이지에서의 동작                |
| :--------------------------------- | :------------------- | :------------------------------ | :------------------------ |
| `href` <br>*(Hypertext Reference)* | 외부 자원과의 **연결 / 링크**  | `<a>`, `<link>`                 | 클릭 시 해당 경로로 **이동**하거나 연결함 |
| `src` <br>*(Source)*               | 외부 자원의 **다운로드 / 삽입** | `<img>`, `<script>`, `<iframe>` | 외부 파일을 가져와 브라우저에 **출력**함  |
## 양식 태그
- \<form>  `non-void element`
	- target ─ 이동할 경로를 출력할 위치 (\_self(기본값), \_blank, \_parent, \_top)
	- action ─ 제출 처리 URL (서버 URL)
	- method ─ 전송 방식
		- GET ─ 자원 조회 및 검색, 전송할 데이터 쿼리 스트링 형태로 URL에 포함 ⇢ 읽기(Read)
			- 데이터는 주소창에 담아서 응답(전송)한다. *(기본값)*
			- 쿼리 스트링 ─ 질문을 위해 사용하는 문자열 데이터 (형태: `?key=value?key=value?..`)
				- 일반적으로 URL-encoding 된 상태이고 어떤 형태의 데이터인지는 header에 명시한다.
		- POST ─ 서버에 변경을 가하는 요청 (*e.g.* 회원가입, 상품등록, 글 작성, …) ⇢ 쓰기(Write)
			- 데이터는 body에 담아서 응답(전송)한다. POST source도 쿼리 스트링으로 구성된다. 

> [!NOTE] HTTP 요청 메서드의 요청-응답 사이클
> **기본 흐름**
> 1. 클라이언트(브라우저, 앱 등)가 서버에 요청(Request)을 보냄
> 2. 서버가 요청을 처리 ⇢ 서버가 응답(Response)을 클라이언트에 돌려줌
> 
> **GET 요청**
> - 데이터를 URL의 쿼리 파라미터에 담아 보냄 (예: `/users?id=5`)
> - 주로 데이터 조회(READ)에 사용
> - URL 자체가 요청 정보이기 때문에 요청 본문(body)이 없음 ⇠ GET 요청은 바디 형식이 있어도 쓰지 않는다. 
> - 브라우저 캐시나 히스토리에 남을 수 있어서 민감한 정보는 부적합
> 
> **POST 요청**
> - 데이터를 요청 본문(body)에 담아 보냄 (JSON, form-data 등)
> - 주로 데이터 생성/제출(CREATE)에 사용
> - URL에 데이터가 노출되지 않고 캐시되지 않음
> 
> **서버의 응답**
> - 요청 메서드가 무엇이든 상관없이 `상태 코드 + 헤더 + 본문 구조`로 전달
> - 상태 코드 ─ 200(성공), 201(생성됨), 400(잘못된 요청), 401(인증 실패), 404(없음), 500(서버 오류) 등
> - 헤더(Headers) ─ Content-Type, 캐시 정책 등 메타 정보
> - 본문(Body) ─ 실제 데이터 (보통 JSON)

- \<input> `void element`
	- type ─ 입력 유형 설정
		- password ─ 비밀번호
		- radio ─ 단일 선택 (checked 사용시 기본 선택)
		- checkbox ─ 다중 선택 (checked 사용시 기본 선택)
		- submit ─ 양식 제출
		- reset ─ 입력 초기화
		- button ─ 일반 버튼
		- email, number, color, range, date, time, datetime, …
	- name
		- 데이터 전송의 기준이 되는 속성, 전송할 데이터에 대한 이름을 명시해야 데이터 전송 가능
		- radio, checkbox 속성의 그룹명
	- value
		- radio, checkbox 등의 속성 사용시 입력값을 직접 지정하는 부가 연계 속성 또는 버튼의 이름 지정 속성
		- 직접 입력하는 형태의 속성(text, email, password 등)인 경우, 사용자 입력값으로 자동 할당
			- 직접 입력하는 형태의 속성인 경우, 미리 value에 값을 넣어두면 양식에 해당 값이 노출된다. 
- \<textarea> `non-void element`
	- placeholder ─ 안내 문구 출력 
	- rows, cols ─ 텍스트 작성 영역 넓이 초기화
- \<button> `non-void element`
	- type ─ 입력 유형 설정
		- submit ─ 양식 제출
		- reset ─ 입력 초기화
		- button ─ 일반 버튼

| 구분  | \<input type="button">                          | \<button>                                              |
| --- | ----------------------------------------------- | ------------------------------------------------------ |
| 요소  | void elemnet                                    | non-void element                                       |
| 성격  | 빈 버튼                                            | submit 기본값                                             |
| 타입  | button<br>submit<br>reset<br><br>※ 반드시 타입 지정 필요 | button<br>submit<br>reset<br><br>※ 타입 미지정 시 submit 기본값 |
| 서식  | 텍스트만 허용                                         | 이미지, 아이콘, 텍스트 서식 허용                                    |

> [!NOTE] submit 타입이 하는 일
> 1. 유효성 검사
> 	- `required`, `type="email"`, `minlength` 같은 게 붙어 있으면 submit 버튼을 눌렀을 때 브라우저가 검사하고 "이 입력란을 작성하세요" 같은 말풍선을 띄운다. (단순 `type="button"`은 브라우저의 형식 검사 없음)
> 2. 데이터 전송
> 	- `action`이 비어 있으면 현재 페이지 주소로 보낸다. (그래서 페이지가 새로고침 됨)
> 	- 초기에는 `action="#"`으로 데이터 전송 동작을 제한할 수 있다. (단순 `type="button"`은 페이지 이동 없음)
> 3. 엔터키 반응
> 	- 마지막 입력란에서 엔터를 치면 submit 버튼이 눌린 것과 같이 동작한다.

- \<select> `non-void element`
	- 콤보박스 또는 드롭다운 선택 
	- option ─ 선택 항목(들) 지정
		- selected ─ 특정 항목이 선택된 상태로 출력 (기본값 설정)
	- multiple ─ 여러 개 선택 가능 `boolean`
	- size ─ 한 번에 보일 선택 항목 개수 지정
- 태그와 입력 요소를 연결하는 방법
	- 입력 요소를 태그로 감싼다. 
		- `<label><input type="radio" name="gender" value="female">여</label>`
		- *e.g.* 라디오 버튼이나 체크박스의 글자를 클릭해도 선택될 수 있도록 한다. 
	- 입력 요소를 for 와 id 속성을 이용해 병렬적으로 연결한다. (권장)
		- `<input type="checkbox" id="hobby_s" name="hobby" value="study">
		  `<label for="hobby_s">공부</label>`
## 목록 태그
- HTML 스펙상 `<ol>`과 `<ul>`은 오직 `<li>`만을 직계 자식으로 허용
	- `<ol>`/`<ul>`은 목록이라는 의미를 가진 태그이고, `<li>`는 그 목록의 항목 하나라는 의미를 가진 태그
		- 따라서 `<li>` 없이 텍스트만 넣으면 이게 몇 번째 항목인지, 어디서 끝나는지 브라우저가 구분할 방법이 없음
	- `<ol>`/`<ul>`에 직접 텍스트를 쓰면 브라우저가 자동 보정해서 일단 제대로 보이게 출력하지만 파싱 에러에 해당 
```html
<body>
    <!-- 글머리 기호 -->
	<ul>
	  <li>
	    <strong>과일</strong>
	    <ul>
	      <li>사과</li>
	      <li>바나나</li>
	    </ul>
	  </li>
	  <li>
	    <strong>채소</strong>
	    <ul>
	      <li>당근</li>
	      <li>오이</li>
	    </ul>
	  </li>
	</ul>
    <!-- 순차열 기호 -->
	<ol>
	  <li>
	    <strong>1단계: 준비</strong>
	    <ol>
	      <li>재료 씻기</li>
	      <li>칼 준비하기</li>
	    </ol>
	  </li>
	  <li>
	    <strong>2단계: 조리</strong>
	    <ol>
	      <li>재료 볶기</li>
	      <li>간 맞추기</li>
	    </ol>
	  </li>
	</ol>
</body>
```
