# CSS 폰트 속성
- `color`
	- 색상명 ─ 지정된 색상 범주 내에서 색상명을 명시함으로써 사용 가능 
	- RGB ─ 빨강, 녹색, 파랑으로 숫자를 표현하는 방법 (0~255) ⇢ 이걸 16진법으로 바꾼 것이 헥사코드
		- RGBA ─ RGB에서 투명도를 표현하는 A(알파채널, 0~1)가 추가된 형태
	- 헥사코드 ─ 동일한 문자 또는 숫자가 반복되는 경우 하나만 써도 인식 가능 (*e.g.* \#ff0000 ⇢ \#f00)
- `font-size`
	- 절대 크기 ─ px(픽셀, 화소 표현), pt(포인트, 인쇄 표현) ⇢ 출력 매체의 물리적 사이즈에 따라 가독성 차이 발생
	- 상대 크기
		- em ─ 폰트 사이즈가 지정된 상위 태그를 기준으로 한다.
		- rem ─ 가장 상위 태그의 폰트 사이즈를 기준으로 한다. html 태그에 설정한 픽셀을 1rem으로 삼는다.
```html
    <style>
        html {font-size: 13px;} /* 이 문서에서는 1rem = 13p 입니다. */
	</style>
```
- `line-height`
	- 행간 ─ 1.2줄 기본값(20%의 여백을 상하단 각 10%씩 할당)
	- 설정 값 단위 ─ 비율(권장), %, px, em, rem, …
- `letter-spacing`(자간: px), `word-spacing`(단어간: px), `word-break`(줄바꿈단위: break-all, keep-all)
- `font-weight`
	- 폰트 두께 ─ normal(기본값~400), bold(두껍게~700)
		- 설정 값 단위 ─ 100 ~ 900 ─ 폰트별 지원 두께가 다르므로 폰트의 상세를 보고 설정해야 한다.
- `text-align` ─ inline property에 대한 정렬이기 때문에 block property에 설정을 적용해야 한다. 
	- left(왼쪽 정렬, 기본값), right(오른쪽 정렬), center(가운데 정렬), junstify(양쪽 정렬)
- `font-style`
	- normal(스타일 없음, 기본값), italic(기울임체), oblique(각도만큼 흘림, *e.g.* `oblique -90~90deg`)
- `text-decoration` ─ underline(밑줄), line-trough(취소선), none(기본값 또는 a태그의 밑줄 제거)
- `font-family: 폰트명, 대체폰트1, 대체폰트2, ..`
	- 폰트명에 공백이 있으면 따옴표로 감싼다. (*e.g.* `font-family: 'Malgun Gothic', 'Apple SD Gothic Neo'`)
		- 시스템 폰트 ─ OS에 설치되어 있는 폰트
			- `font-display: swap` ─ 폰트 로딩 전에 기본 폰트를 적용하고 로딩이 끝나면 현재 폰트를 적용
		- 웹 폰트 ─ OS 설치 여부에 상관 없이 웹 호스팅 기반으로 공유 가능한 폰트
```css
/* 웹폰트 import */
@import url('https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@100..900&display=swap')

/* 웹폰트 전역설정 */
* {
	font-family: "Noto Sans KR", sans-serif;
	font-size: 25px;
   }
```
# CSS 박스 모델
- box-sizing ─ 설정하는 width, height의 기준이 되는 영역 지정
	- content-box ─ content 까지의 영역 (기본값)
		- pading이나 border 두께를 변경해도 content 크기는 변경되지 않는다. (content-box로 너비와 높이를 고정)
	- border-box ─ border 까지의 영역
		- pading이나 border 두께를 변경하면 content 크기도 변경된다. (border-box이기 때문에 그 안에서 변경)
		- 레이아웃 구성 시 예측이 가능하고 padding, border가 모두 포함되는 고정된 너비와 높이로 작업 가능
			- `* { box-sizing: border-box;}` ─ html 페이지 내의 모든 box-sizing에 border-box 적용

- margin ─ 바깥 여백
	- block property ─ 상하좌우 여백 모두 가능 
		- 수치를 나열하면 시계방향으로 12시 ⇢ 3시 ⇢ 6시 ⇢ 9시가 적용된다. 
			- `상-우-하-좌` 또는 `상-좌우-하` 또는 `상하-좌우` 또는 `값 하나` 형식으로도 설정 가능
		- 블록 간 margin이 중첩되는 경우 가장 큰 margin 값으로 대체된다.
		- 가운데 정렬 
			- *e.g.* `margin: 100px auto;` ─ 위 아래 100px 바깥 여백을 두고 좌우는 균등하게 여백 배분
		- longhand ─ `margin-top`, `margin-bottom`, `margin-left`, `margin-right`
	- inline property ─ 좌우 여백만 가능
- padding ─ 안쪽 여백
	- 세부 설정은 margin과 동일하게 적용
# CSS display 속성
- block ⇢ block이 아닌 요소를 block으로 바꾼다. (inline 요소를 block 요소로 바꾼다.)
	- e.g. `div.box {display: inline;}`
- inline ⇢ inline이 아닌 요소를 inline으로 바꾼다. (block 요소를 inline 요소로 바꾼다.)
	- e.g. `span.box {display: block;}`
- inline block
	- 줄개행을 하지 않지만 공간의 특성을 갖기 때문에 내외부 여백의 상하좌우 여백 설정 모두 가능
	- 블록 간 margin이 중첩되는 경우 각각 독립적으로 여백이 적용된다. (margin에서는 inline 특성이 작용)
- none ─ 요소가 있던 자리를 없애면서 해당 요소를 감추기
	- *cf.* `visibility: hidden` ─ 요소가 있던 자리는 남겨두면서 해당 요소를 감추기
## Flexbox
- 1차원 정렬
	- container ─ 부모 속성. `display: flex` 적용 요소
	- items ─ 자식 속성. `display: flex` 받는 요소
1. 부모 요소에 설정하고 자식 요소에 적용한다. (자식에 스타일을 일괄 적용하기 위해 부모가 통제한다.)
	- 부모 요소에 지정된 클래스 선택자에 해당하는 CSS 영역에 `display: flex` 적용하고 그 아래 설정 적용
	- `flex-direction` ─ 정렬 방향 설정
	![[flex_direction_demo 2.png]]
	- `justify-content` ─ 정렬 속성 제어
	![[justify_content_demo.png]]
	- `align-items` ─ 자식 요소 배치
		- stretch ─ 부모 요소의 크기에 맞춰 컨테이너를 늘리는 것 (기본값)
			- *e.g.* 자식 요소에 없는 height 값이 부모 쪽에 있으면 자식 요소에 height 값을 그대로 적용한다. 
![[align_items_demo 2.png]]
2. 자식 요소에 직접 설정하고 자기 자신에 적용한다. (필요하면 자식 요소의 스타일이 부모 설정을 덮어 쓴다.)
	- 자식 요소에 지정된 클래스 선택자에 해당하는 CSS 영역에 아래 아이템 속성을 적용
	- 부모의 `display: flex` 를 전제 조건으로 삼되 자식 요소가 개별적으로 스타일 설정을 하고 싶을 때 사용
		- *e.g.* `align-self`가 `align-items`보다 우선한다.
- `flex-grow` ─ 컨테이너에 남는 공간이 있을 때 아이템들이 공간을 나눠 가지는 비율 (기본값 0)
- `flex-shrink` ─ 컨테이너에 남는 공간이 없을 때 얼마나 줄어들지 정하는 기준
	- 기본값 1일때 크기가 줄어들고 0일 때 절대 줄어들지 않아서 아이템이 컨테이너 밖으로 넘칠 수 있다. 
	- 되도록 `flex-shrink` 단독으로 쓰지 않고 `flex: none` 또는 `flex: 0 1 auto`로 grow 및 basis와 함께 쓴다. 
- `flex-basis` ─ grow, shrink 설정이 적용되기에 앞서 전제되는 아이템의 크기 설정
	- auto 일 때 컨텐츠 크기를 기준으로 하고 0% 인 경우 콘텐츠 크기를 무시하고 0부터 시작한다.
- `align-self` ─ 컨테이너의 `align-items` 설정을 무시하고 지정된 아이템에 대해 교차축 정렬을 개별 지정
- `order` ─ 코드 순서는 그대로 두고 화면에 그려지는 시각적 순서를 지정해 바꾼다. (숫자가 작을수록 앞에)
