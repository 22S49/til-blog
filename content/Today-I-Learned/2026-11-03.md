덮어쓰기는 폴더의 현재 파일만 바꾸고, 커밋해 둔 내 버전은 git 이력에 그대로 남아 있어.

**덮어쓰기 전에 커밋해 둔 경우**

```
내 코드를 커밋  →  강사 코드로 덮어씀  →  git diff 로 "강사가 뭘 바꿨는지" 바로 확인
                                      →  git checkout -- 파일  로 내 버전 복구
                                      →  git restore -p  로 필요한 부분만 골라 합치기
```

- 오늘 내가 파일 목록과 수정 시각을 일일이 비교해서 찾던 걸 `git diff` 한 줄이 해 줘. 수정 시각이 전부 같아서 구분이 안 됐던 것도 해결돼.
- 강사 코드가 내 변경을 덮어쓴 부분, 새로 생긴 파일, 안 건드린 부분이 줄 단위로 나와.

**한계도 있어**

- **덮어쓰기 전에** 커밋해야 해. `11_backend_prac`은 지금 `??`(추적 안 됨) 상태라서 먼저 `git add`가 필요해. 이미 덮어쓴 오늘 작업은 이력이 없어서 되살릴 수 없어.
- `.gitignore`에 `.env*`가 들어 있어서 `.env.local`은 커밋되지 않아. 이건 비밀번호가 올라가지 않으니 좋은 쪽이지만, 따로 백업해야 해.

**수업 중에 쓰기 편한 습관**

```
git add 11_backend_prac
git commit -m "wip: 수업 전 내 코드"      # 강사 코드 받기 직전에 한 번
```

- 이 폴더만 지정해서 커밋하면 저장소의 다른 변경사항(다른 폴더의 삭제 표시 등)은 안 섞여.
- 강사 코드를 받은 뒤에 `git diff`를 보고, 필요하면 한 번 더 커밋하면 돼.

**파이썬 테스트 코드를 실행할 때 경로 문제를 해결하고 테스트를 자동 탐색하여 실행하는 명령어**입니다.

크게 **환경 변수 설정**과 **테스트 실행** 두 부분으로 쪼개서 설명해 드릴게요.

---

1. `$env:PYTHONPATH='src'` : 환경 변수 설정

- **의미**: **윈도우 파워셸(PowerShell)** 환경에서 파이썬이 모듈(코드 파일)을 찾을 때 **`src` 폴더를 가장 먼저 검색하도록 경로(PYTHONPATH)를 추가**하는 명령어입니다.
- **왜 쓸까?**: 보통 소스코드를 `src/` 폴더 안에 모아두고, 테스트 코드는 외부 `tests/` 폴더에 따로 둡니다. 이 설정을 안 하면 테스트 코드에서 `import my_module`을 했을 때 파이썬이 `src` 내부의 코드를 찾지 못하고 `ModuleNotFoundError`를 일으킵니다.
- _(참고: macOS/Linux 터미널에서는 `$env:` 대신 `export PYTHONPATH=src`로 씁니다.)_

---

2. `uv run python -m unittest discover -s tests -t . -v` : 테스트 실행

이 뒷부분은 파이썬 내장 테스트 도구인 `unittest`를 **uv**라는 최신 패키지 매니저로 실행하는 명령어입니다. 상세 옵션은 다음과 같습니다.

- **`uv run`**: 파이썬 가상환경(venv)을 자동으로 관리해 주는 초고속 툴인 **uv**를 통해 명령어를 실행합니다. 프로젝트에 필요한 의존성(라이브러리)이 설치된 올바른 환경에서 실행되도록 보장합니다.
- **`python -m unittest`**: 파이썬 내장 테스트 프레임워크인 `unittest` 모듈을 실행합니다.
- **`discover`**: 테스트 파일을 자동으로 찾아내라(탐색하라)는 명령입니다. 기본적으로 `test_*.py` 패턴의 파일들을 찾아냅니다.
- **`-s tests`**: **S**tart(시작) 디렉토리의 약자로, 테스트 파일을 찾기 시작할 폴더를 **`tests` 폴더로 지정**합니다.
- **`-t .`**: **T**op-level(최상위) 디렉토리의 약자로, 프로젝트의 루트(현재 폴더 `.`)를 기준으로 설정합니다. 앞서 설정한 `PYTHONPATH`와 연동되어 모듈 수입(import) 경로가 꼬이지 않게 도와줍니다.
- **`-v`**: **V**erbose(상세히)의 약자로, 어떤 테스트가 성공하고 실패했는지 **결과를 화면에 아주 자세하게 출력**해 달라는 옵션입니다.

> **"윈도우 파워셸에서 코드가 들어있는 `src` 폴더 경로를 파이썬에 알려준 뒤, `uv`를 이용해 `tests` 폴더 안에 있는 모든 테스트 파일들을 찾아서 상세히 실행해라."** 라는 의미입니다.
